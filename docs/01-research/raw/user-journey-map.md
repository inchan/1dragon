# 상품 사진 → 숏폼 마케팅 영상 자동 생성 SaaS: 사용자 여정 맵

> **서비스 개요**: 상품 사진 업로드 → AI가 TikTok/Reels/Shorts용 마케팅 영상 자동 생성
> **타겟**: B2B(브랜드, 에이전시, 대기업) + B2C(1인셀러, 인플루언서)
> **수익 모델**: Freemium + 구독(SaaS)

---

## 1. B2B 사용자 여정 맵 (마케팅 담당자 / 에이전시 기준)

### 여정 개요

B2B 구매자는 **다단계 의사결정(팀 합의, 예산 승인)** 을 거치며, 평균 구매 여정이 **6~10주**에 달한다. ROI 증명과 팀 협업 기능이 전환의 핵심 요인이다.

| 단계 | 터치포인트 | 사용자 행동 | 감정 / 생각 | 이탈 위험 요인 | 기회 |
|------|-----------|------------|-------------|---------------|------|
| **인지 (Awareness)** | LinkedIn 광고, 업계 블로그, 컨퍼런스 부스, SEO(검색: "상품 영상 자동 생성"), 경쟁사 비교 콘텐츠, 파트너 추천 | 숏폼 영상 제작 비용·시간 문제 인식, "AI 영상 생성" 키워드 검색, 경쟁사 사례 탐색, 업계 리포트 다운로드 | "매번 외주 맡기기엔 비용이 너무 크다" / "팀 내 영상 제작 역량이 부족하다" / "경쟁사는 이미 숏폼을 활용 중인데…" | 메시지가 일반적 AI 도구로 인식되어 차별점 파악 불가 (이탈률 ~70%) | **상품 사진 → 영상** 이라는 구체적 Use Case 강조, ROI 계산기 제공 ("외주 대비 월 ₩X 절감"), 업종별 사례 영상 랜딩 |
| **고려 (Consideration)** | 제품 웹사이트, 데모 영상, 비교 페이지(vs Canva/InVideo), 세일즈 미팅, G2/Capterra 리뷰, 무료 평가판 | 기능 비교표 확인, 데모 요청/세일즈 콜 진행, 내부 공유용 자료 수집, 보안·컴플라이언스 확인, 경쟁 도구 3~5개 비교 | "우리 브랜드 톤에 맞출 수 있나?" / "대량 생산이 가능한가?" / "기존 DAM/CMS와 연동되나?" / "보안 인증은?" | 경쟁 도구 대비 차별점 불명확 (전환율 Visitor→Trial: B2B SaaS 평균 **2~5%**), 엔터프라이즈 보안 요구 미충족 | 브랜드 가이드라인 커스텀 데모, API/연동 문서 공개, SOC 2/GDPR 인증 배지, **무료 PoC(3개 영상)** 제공 |
| **가입 (Sign-up)** | 가입 페이지, SSO/Google Workspace 연동, 팀 초대 플로우, CRM 연동 설정 | 업무 이메일로 가입, 팀원 초대(평균 2~3명), 브랜드 에셋 업로드(로고, 폰트, 컬러), 기존 도구 연동 설정 | "설정이 복잡하지 않을까?" / "팀원들이 잘 쓸 수 있을까?" / "IT 부서 승인이 필요한가?" | 복잡한 온보딩 (B2B SaaS 온보딩 완료율 평균 **40~60%**), SSO 미지원 시 IT 부서 반대 | 5분 이내 첫 영상 생성 가능한 **Quick Start**, 전담 CSM 배정(Enterprise), 브랜드 키트 자동 감지 |
| **첫 영상 생성 (Activation)** | 에디터 UI, 상품 사진 업로드, AI 스타일 선택, 프리뷰/편집, 다운로드/공유 | 상품 사진 1~3장 업로드, AI 추천 스타일 중 선택, 텍스트·BGM 커스텀, 15/30/60초 포맷 선택, 프리뷰 확인 후 다운로드 | "와, 진짜 이게 자동으로?" (Aha Moment) / "근데 우리 브랜드 느낌이랑 좀 다른데…" / "수정하려면 어디를 건드려야 하지?" | **Time-to-Value > 10분 시 이탈 급증** (Creative SaaS 평균 TTv: 7~12분), AI 결과물 품질 불만족 | 업로드 즉시 3가지 스타일 프리뷰 자동 생성, **Aha Moment까지 3클릭 이내** 설계, 브랜드 톤 미세 조정 슬라이더 |
| **반복 사용 (Retention)** | 대시보드, 캠페인 관리, 팀 협업 도구, 성과 분석, 벌크 생성, API | 주간 캠페인용 영상 배치 생성, A/B 테스트 버전 제작, 팀 리뷰·승인 워크플로우, 성과 대시보드 모니터링 | "매주 콘텐츠 제작 시간이 80% 줄었다" / "대시보드에서 어떤 스타일이 잘 먹히는지 보인다" / "팀 협업이 편해졌다" | Week 1→4 리텐션 드롭 (B2B SaaS 평균 Day-30 리텐션: **40~60%**), 반복 결과물의 단조로움, 팀 채택률 저조 | **캠페인 템플릿 라이브러리**, 성과 기반 AI 추천("이 상품엔 이 스타일이 CTR 23% 높음"), 팀 활동 리포트, 신규 스타일 주간 업데이트 |
| **구독 전환 (Revenue)** | 가격 페이지, 사용량 알림, 업그레이드 프롬프트, 세일즈 미팅, 견적서/계약 | 무료 크레딧 소진 알림 확인, 팀 내 ROI 보고서 작성, 상위 플랜 기능 비교, 예산 승인 요청, 연간 계약 협상 | "무료로 써본 결과 확실히 효과가 있다" / "상사에게 어떻게 보고하지?" / "연간 결제하면 얼마나 할인되나?" | **Freemium→Paid 전환율: B2B SaaS 평균 3~7%** (PLG 모델), 내부 예산 승인 지연, 경쟁 도구로 이탈 | **ROI 대시보드 자동 생성**(외주비 대비 절감액, 제작 시간 절감), 연간 결제 20~30% 할인, 엔터프라이즈 맞춤 견적, Procurement 지원 자료 |
| **추천 (Referral)** | G2/Capterra 리뷰, 사례 연구, 파트너 프로그램, 커뮤니티, 웨비나 | 리뷰 작성, 사례 연구 참여, 동종 업계 추천, 파트너/리셀러 등록, 웨비나 발표 | "다른 팀에도 추천해야겠다" / "우리 사례가 공개되면 브랜딩에도 도움" / "파트너 수수료도 받을 수 있네" | NPS 수집 시점 부적절, 인센티브 부재, 추천 프로세스 복잡 | **공동 마케팅 사례 연구**(고객사 로고 노출), 파트너 수수료 프로그램, 추천 1건당 크레딧 보상, 베타 기능 우선 접근 |

### B2B 핵심 메트릭 벤치마크

| 메트릭 | 업계 평균 | 목표치 | 측정 방법 |
|--------|----------|--------|----------|
| Visitor → Trial | 2~5% | 5~8% | GA4 Funnel |
| Trial → Activation (첫 영상 생성) | 35~50% | 60%+ | Product Analytics |
| Activation → Week-4 Retention | 40~60% | 55%+ | Cohort Analysis |

| Net Revenue Retention | 100~120% | 115%+ | MRR Tracking |
| Time-to-First-Value | 7~12분 | <5분 | Event Tracking |

## 2. B2C 사용자 여정 맵 (1인셀러 / 인플루언서 기준)

### 여정 개요

B2C 사용자는 **개인 의사결정(빠름)** 이 특징이며, **즉각적 결과물 품질**과 **가격 민감도**가 전환의 핵심 요인이다. 평균 구매 여정은 **1~7일**로 짧다.

| 단계 | 터치포인트 | 사용자 행동 | 감정 / 생각 | 이탈 위험 요인 | 기회 |
|------|-----------|------------|-------------|---------------|------|
| **인지 (Awareness)** | TikTok/Instagram 광고, 인플루언서 후기, 검색("상품 영상 만들기 쉽게"), 커뮤니티(셀러 카페/디스코드), 앱스토어 피처링 | 숏폼 영상 직접 촬영·편집의 어려움 체감, SNS에서 다른 셀러의 AI 영상 목격, "나도 이렇게 만들 수 있나?" 검색 | "영상 편집 배울 시간이 없다" / "전문가처럼 만들고 싶은데 도구가 너무 비싸다" / "저 셀러는 어떻게 매일 영상을 올리지?" | 수많은 무료/저가 대안 존재 (CapCut, Canva Free), "또 하나의 AI 도구" 피로감 | **Before/After 비교 숏폼 광고** (상품 사진 → 완성 영상 과정 15초), 셀러 커뮤니티 바이럴, 무료 체험 강조 |
| **고려 (Consideration)** | 앱스토어 리뷰, 유튜브 리뷰, 가격 비교, 무료 체험 페이지, SNS 후기 | 앱 스크린샷/영상 확인, 무료 vs 유료 기능 비교, 리뷰 점수 확인(4.5+ 기대), 비슷한 도구 2~3개 비교, 지인에게 물어봄 | "무료로 얼마나 쓸 수 있지?" / "워터마크 있으면 안 되는데…" / "내 상품 카테고리에도 잘 맞을까?" | **가격 장벽** (1인셀러 월 구독 부담), 무료 대안 대비 가치 불명확, 앱 리뷰 4.0 미만 시 즉시 이탈 | 워터마크 없는 월 3개 무료 영상, 카테고리별 샘플 갤러리 (패션/뷰티/식품/전자기기), **"30초 만에 첫 영상"** 메시지 |
| **가입 (Sign-up)** | 소셜 로그인(카카오/네이버/Google), 앱 다운로드, 웹 가입 | 소셜 로그인 1탭 가입, 카테고리 선택(패션/뷰티/식품 등), 첫 상품 사진 업로드 유도 | "가입은 간단하네" / "바로 써볼 수 있나?" / "개인정보 수집이 좀 꺼림칙…" | 가입 프로세스 3단계 초과 시 이탈률 급증 (모바일 가입 완료율 평균 **25~40%**), 앱 용량/권한 요청 과다 | **소셜 로그인 원탭 → 즉시 에디터** 진입 (가입과 동시에 사진 업로드), 최소 권한 요청, 가입 2단계 이내 |
| **첫 영상 생성 (Activation)** | 모바일/웹 에디터, 갤러리에서 사진 선택, 원탭 생성, 프리뷰, SNS 직접 공유 | 갤러리에서 상품 사진 선택(1~2장), "자동 생성" 버튼 탭, 15초 기다림, 결과물 프리뷰, BGM/텍스트 간단 수정, SNS 공유 또는 저장 | **"오! 이거 진짜 되네!"** (Aha Moment) / "생각보다 괜찮다" 또는 "음… 좀 어색한데" / "바로 올려야지!" | **AI 결과물 품질이 기대 이하** (특히 복잡한 상품: 액세서리, 투명 포장 등), 생성 대기 시간 >15초, 편집 UI 복잡 | **사진 선택 → 결과물까지 30초 이내**, 상품 카테고리 자동 감지 + 최적 스타일 적용, SNS 직접 공유 버튼, 실패 시 "다른 스타일로 다시 만들기" 원탭 |
| **반복 사용 (Retention)** | 푸시 알림, 트렌드 템플릿, 내 영상 성과 알림, 커뮤니티, 새 기능 업데이트 | 신상품 등록 시마다 영상 생성, 트렌드 BGM/효과 적용, 성과 좋은 영상 스타일 재활용, 커뮤니티에 결과물 공유 | "이제 영상 때문에 스트레스 안 받는다" / "새로운 트렌드 템플릿 나왔네" / "내 영상 조회수가 올랐다!" | **Day-7 리텐션 B2C 앱 평균: 20~25%**, Day-30: **8~12%**, 콘텐츠 단조로움, 새로운 무료 도구 출시 | **트렌드 기반 추천** ("이번 주 인기 BGM으로 리메이크"), 영상 성과 간단 분석(조회수 추적), 주간 새 스타일/효과 업데이트, 연속 사용 보상(스트릭) |
| **구독 전환 (Revenue)** | 인앱 구매, 가격 페이지, 업그레이드 팝업, 크레딧 소진 알림 | 무료 크레딧 소진, 워터마크 제거 필요성 체감, 고급 기능(4K, 커스텀 폰트) 필요, 월간/연간 플랜 비교 | "무료로는 한계가 있네" / "월 ₩9,900이면 괜찮은 건가?" / "비슷한 앱은 더 싼데…" | **B2C SaaS Freemium→Paid 전환율: 2~5%**, 가격 민감도 높음, 경쟁 앱 대비 가격 프리미엄 정당화 어려움 | **₩9,900/월 Starter** (심리적 만원 이하), 첫 달 50% 할인, 연간 결제 시 2개월 무료, "프로 셀러" 뱃지 제공, 생성 영상 수 기반 단계적 가격 |
| **추천 (Referral)** | SNS 공유, 추천 코드, 리뷰 보상, 커뮤니티 | 결과물을 SNS에 공유(자연 바이럴), 추천 링크 전달, 앱스토어 리뷰 작성, 셀러 커뮤니티에 후기 | "친구도 이거 쓰면 좋겠다" / "추천하면 뭐 주나?" / "내 후기가 도움이 됐으면" | 공유 시 서비스 워터마크/로고 부재(바이럴 기회 상실), 추천 보상 매력 부족 | **영상 내 미니 브랜딩**(우측 하단 작은 로고, 무료 사용자), 추천 1명당 프리미엄 영상 3개 무료, 공유 시 자동 추천 링크 삽입, 리뷰 작성 시 크레딧 보상 |

## 3. 단계별 핵심 이탈 위험 및 대응 전략

### B2B 이탈 위험 & 대응

| 단계 | 핵심 이탈 위험 | 심각도 | 대응 전략 | 성공 지표 |
|------|---------------|--------|----------|----------|

## 4. 핵심 인사이트

### 4.1 B2B vs B2C 여정의 핵심 차이점

| 차원 | B2B (마케팅 담당자/에이전시) | B2C (1인셀러/인플루언서) |
|------|---------------------------|------------------------|
| **의사결정 구조** | 다단계 합의 (담당자→팀장→CMO→구매팀), 6~10주 | 개인 즉시 결정, 1~7일 |
| **핵심 전환 동인** | ROI 증명, 팀 협업, 보안 인증, API 연동 | 즉각적 결과물 품질, 가격, 사용 편의성 |
| **Aha Moment** | "브랜드 가이드라인에 맞는 영상이 자동으로 나온다" | "사진만 올렸는데 진짜 영상이 됐다!" |
| **이탈 최대 위험** | Time-to-Value 초과 + 팀 채택 실패 | AI 결과물 품질 불만족 + Day-7 리텐션 드롭 |
| **가격 민감도** | 낮음 (연 수천만원 마케팅 예산 중 일부) | 높음 (월 ₩1만도 심리적 저항) |
| **성공 지표** | Net Revenue Retention > 115%, 팀 MAU/시트 > 60% | Day-30 Retention > 18%, K-factor > 0.8 |
| **리텐션 드라이버** | 워크플로우 통합(기존 도구와 연동), 팀 의존성 | 트렌드 업데이트, 보상/게이미피케이션, 커뮤니티 |
| **추천 메커니즘** | 사례 연구, 파트너 프로그램, 업계 이벤트 | SNS 바이럴, 추천 코드, 커뮤니티 후기 |

### 4.2 제품 설계 시사점

| 시사점 | 설명 | 우선순위 |
|--------|------|---------|
| **듀얼 온보딩 트랙** | B2B: 브랜드 키트 설정 → 팀 초대 → 첫 캠페인 / B2C: 사진 선택 → 즉시 생성 → 공유. 동일 코어 엔진이지만 진입 경험을 분리해야 한다 | P0 |
| **Time-to-Value 극단적 단축** | B2B: 가입 전 데모 영상 제공(리드 캡처), B2C: 가입 없이 1개 영상 생성 가능("Try Before Sign-up"). **첫 Aha Moment까지의 클릭 수를 3 이하로 설계** | P0 |
| **AI 품질 = 제품의 생사** | 결과물 품질이 기대 이하면 어떤 마케팅도 무의미. **카테고리별 특화 모델**(패션 vs 식품 vs 전자기기), 지속적 품질 피드백 루프(👍/👎 → 모델 개선), A/B 테스트 인프라 | P0 |
| **팀 협업 레이어 (B2B 전용)** | 리뷰·승인 워크플로우, 브랜드 가이드라인 잠금, 역할 기반 권한, 팀 활동 대시보드. 이것이 경쟁 도구(Canva 등)와의 핵심 차별점 | P1 |
| **트렌드 엔진 (B2C 핵심)** | 매주 TikTok/Reels 트렌드 BGM·효과·전환 스타일 자동 반영. "이번 주 트렌드로 내 상품 영상 리메이크" 푸시. 이것이 반복 방문의 핵심 동인 | P1 |
| **성과 연결 (양쪽 공통)** | 생성한 영상의 SNS 성과를 서비스 내에서 추적할 수 있으면, 사용자는 "이 도구가 매출에 기여한다"는 인식을 갖게 됨 → 리텐션·전환 동시 강화 | P1 |

### 4.3 가격 전략 시사점

| 세그먼트 | 권장 가격 구조 | 근거 |
|---------|---------------|------|
| **B2C Free** | 월 3개 영상 (워터마크 없음, 미니 브랜딩 있음) | 가치 체감 + 자연 바이럴 (Canva Free 모델 참고) |
| **B2C Lite** | ₩4,900/월 (월 10개 영상, HD) | 1인셀러 심리적 "만원 이하" 가격대. 연간 ₩3,900/월 |
| **B2C Pro** | ₩9,900/월 (월 30개 영상, 4K, 커스텀 폰트/BGM) | 활발한 인플루언서용. 연간 ₩7,900/월 |
| **B2B Starter** | ₩49,000/월 (5시트, 월 100개 영상, 브랜드 키트) | 소규모 마케팅 팀. 연간 ₩39,000/월 |
| **B2B Professional** | ₩149,000/월 (15시트, 무제한 영상, API, 팀 협업) | 중견 기업/에이전시. 연간 ₩119,000/월 |
| **B2B Enterprise** | Custom (무제한 시트, SLA, SSO, 전담 CSM, 온프레미스 옵션) | 대기업. ARR ₩2,000만+ 타겟 |

**가격 전략 핵심 원칙:**
- B2C는 **영상 수 기반 단계적 과금** (사용량 체감 → 자연스러운 업그레이드)
- B2B는 **시트 + 기능 기반 과금** (팀 규모 확대 = 수익 확대, Net Expansion)
- **Freemium → 첫 유료 전환 장벽을 최대한 낮추되**, 핵심 가치(워터마크 제거, 고화질, 브랜드 커스텀)는 유료에만 포함
- 참고: Canva Pro $12.99/월, InVideo $25/월, Pictory $23/월 — 한국 시장은 이보다 **20~30% 낮은 가격** 이 진입에 유리

### 4.4 마케팅 전략 시사점

| 전략 | B2B | B2C |
|------|-----|-----|
| **핵심 채널** | LinkedIn, 업계 이벤트, SEO(검색 의도 캡처), 세일즈 아웃바운드 | TikTok/Instagram 광고, 인플루언서 시딩, 셀러 커뮤니티, ASO |
| **메시지 프레임** | "마케팅 팀의 영상 생산성을 10배로" / "외주비 80% 절감" (ROI 중심) | "사진만 올리면 30초 만에 영상 완성" / "영상 편집 몰라도 OK" (편의성 중심) |
| **콘텐츠 전략** | 업종별 사례 연구, ROI 백서, 웨비나, 비교 콘텐츠(vs Canva/InVideo) | Before/After 숏폼, 셀러 후기 UGC, 트렌드 챌린지, 튜토리얼 Reels |
| **전환 전략** | PLG(Product-Led Growth) + 세일즈 하이브리드: Free Trial → CSM 터치 → 엔터프라이즈 세일즈 | PLG 순수: 앱 내 자연 업그레이드 퍼널, 크레딧 소진 시점 업그레이드 프롬프트 |
| **리텐션 전략** | 팀 활용도 리포트, 월간 ROI 요약 이메일, CSM 정기 체크인, 신기능 웨비나 | 트렌드 푸시 알림, 주간 새 스타일, 스트릭 보상, 커뮤니티 챌린지 |
| **리퍼럴 전략** | 파트너 프로그램(에이전시 리셀러), 공동 사례 연구, 고객 자문 위원회 | 추천 코드 보상, SNS 공유 시 자동 링크, 앱 리뷰 크레딧, UGC 콘테스트 |
| **핵심 CAC 목표** | LTV:CAC > 3:1, CAC 회수 기간 < 12개월 | CPI < ₩3,000, LTV:CAC > 3:1, 오가닉 비중 > 40% |

## 부록: 사용자 여정 시각화 (감정 곡선)

### B2B 감정 곡선

```
만족도
  ↑
  5 │                              ★ 반복 사용
  4 │            ★ 가입            ╱  (팀 정착)        ★ 추천
  3 │  ★ 인지  ╱     ╲   ★ 첫영상╱                  ╱
  2 │        ╱        ╲  ╱                 ★ 구독전환╱
  1 │      ╱  ★ 고려   ╲╱                  (예산승인 스트레스)
  0 ├────────────────────────────────────────────────→ 시간
       1주    2주    3주    4주    2개월   3개월   6개월
```

### B2C 감정 곡선

```
만족도
  ↑
  5 │         ★ 첫영상생성 ("오!")
  4 │  ★ 인지╱  ╲                    ★ 추천
  3 │      ╱     ╲   ★ 반복 사용   ╱
  2 │    ╱★가입    ╲ ╱  (트렌드)  ╱
  1 │   ╱           ╲   ★ 구독전환╱
  0 │  ╱  ★ 고려     ╲  (가격 저항)
    ├────────────────────────────────────────→ 시간
      1일    3일    7일    14일    30일    60일
```

### 핵심 차이:
- **B2B**: 완만한 상승 → 첫 영상에서 소폭 딥(브랜드 맞춤 부족) → 팀 정착 후 안정적 상승 → 구독 전환 시 일시적 딥(예산 승인)
- **B2C**: 급격한 상승(첫 영상 Aha) → 빠른 하락(Day-7 리텐션 위기) → 트렌드/보상으로 회복 → 구독 전환 시 가격 저항
