# 의사결정 가이드 및 리스크 관리 (Guide & Risk Matrix)

## 1. 의사결정 가이드 (Go/No-Go Checklists)

### Week 3: 핵심 파이프라인 마일스톤
- [ ] "사진 1장 -> 15초 영상" E2E 성공률 80%+
- [ ] 하이브리드 엔진 품질 내부 평가 55%+
- [ ] 생성 시간 120초 이내
- [ ] 상품 정체성 보존 deltaE < 5
> **실패 시**: Path C 진입, 기술 피봇 검토

### Week 6: MVP 완성도
- [ ] F001~F009 기능 동작
- [ ] 결제 시스템 동작 (Free/Starter)
- [ ] 60초 이내 생성 시간 (중위값)
- [ ] 베타 테스터 100명 확보
> **실패 시**: Path B, 축소 런칭 결정

### Week 12: PMF 1차 신호
- [ ] Activation Rate 35%+
- [ ] NPS 30+
- [ ] 유료 전환율 2%+
- [ ] Week 1 리텐션 20%+
- [ ] K-factor 0.2+
> **실패 시**: UX 개선, 품질 개선, 가격 실험

### Month 4: Seed 라운드 Go/No-Go
- [ ] MRR ₩150만+
- [ ] 유료 전환율 3%+
- [ ] 월간 성장률 20%+
- [ ] LTV/CAC 2x+
> **실패 시**: 부트스트래핑 전환 또는 피봇
