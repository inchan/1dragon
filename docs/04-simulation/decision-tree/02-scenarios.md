# 핵심 시나리오 분석 (Key Scenarios)

## 1. Best Case Path (최선의 경로)

```
Path A (6주 완성) -> 성공 (완성율 >70%, NPS >40) -> 고전환 (CVR >5%) -> 투자 유치 성공 (Seed ₩10억)
```

- **확률 추정**: 약 1.9% (2% 미만)
- **주요 지표**: Month 6 기준 MAU 5,000, 유료 350명, MRR ₩500만
- **필요 조건**: 개발 일정 준수, API 안정성, 하이브리드 엔진 품질 확보, 커뮤니티 바이럴

## 2. Most Likely Path (가장 가능성 높은 경로)

```
Path A/B (6~8주 완성) -> 보통 (완성율 40~70%, NPS 10~40) -> 저전환 (CVR 1~5%) -> 부트스트래핑 또는 조건부 Seed
```

- **확률 추정**: 약 23%
- **주요 지표**: Month 6 기준 MAU 5,000, 유료 180명, MRR ₩200만
- **핵심 의사결정**: 가격 실험(Month 2), Seed vs 부트스트래핑 결정(Month 4), 스마트스토어 연동

## 3. Worst Case Path (최악의 경로)

```
Path C (기술 장애) -> 피봇 시도 -> 피봇 실패 -> 셧다운
```

- **확률 추정**: 약 3%
- **주요 지표**: Week 3 기술 실패 확인, Week 8 피봇 실패
- **대응**: 빠른 피봇(2주 내) 시도 후 실패 시 잔여 자금 보존하며 셧다운

## 4. Hidden Danger Path (숨겨진 위험 경로)

```
Path A (6주 완성) -> 성공 (NPS >40, K-factor >0.3) -> 전환 실패 (CVR <1%) -> 자금 소진
```

- **위험 요소**: "사용자는 열광하지만 돈은 안 냄". 무료 사용자 폭증으로 API 비용 급증, 매출 부재.
- **조기 신호**: 무료 소진율 > 80% 이면서 유료 전환율 < 1%
- **비상 대응**: 무료 쿼터 즉시 축소, 품질 차등 강화, API 비용 최적화

## 5. Pivot Paths (피봇 경로)

실패 시나리오에서의 대안 방향:

| 순위 | 방향 | 설명 | 성공 확률 |
|:----:|------|------|:---------:|
| 1 | **P-C: B2B 영상 에이전시** | 에이전시 대상 서비스형 모델 (즉시 매출) | 50% |
| 2 | **P-A: 이커머스 이미지 AI** | 상품 사진 배경 교체/향상 (기술 난이도 낮음) | 45% |
| 3 | **P-D: 네이버 클립 전용** | 범위 극한 축소, 네이버 생태계 집중 | 40% |
| 4 | **P-B: AI 카피라이팅** | 글로벌 시장 크지만 경쟁 치열 | 25% |
