# 그룹별 관점 분석 (Perspectives)

## 1. B2B 고객 관점 (김민수, 이서연, 박준혁)

### 핵심 관심사 Top 5

| 순위 | 관심사 | 근거 |
|:----:|--------|------|
| 1 | **브랜드 가이드라인 완벽 반영** | 김민수: "AI가 만든 티가 나서 브랜드 이미지에 부정적이지 않을까" (USER_RESEARCH). 박준혁: 글로벌 본사 BI 가이드라인 + 화장품법 동시 준수 필요 |
| 2 | **대량 처리 능력 (Batch + API)** | 이서연: 클라이언트 1개 추가 = 편집자 0.3~0.5명 추가 필요한 구조적 한계. 박준혁: SKU 400개 중 영상 커버리지 10%에 불과 |
| 3 | **엔터프라이즈 보안/컴플라이언스** | 박준혁 의사결정 기준 1위: 엔터프라이즈 보안/컴플라이언스 (USER_RESEARCH). SSO, RBAC, DPA, SOC2 필수 |
| 4 | **비용 절감 ROI 증빙** | 이서연: 클라이언트당 영상 제작 원가 40% 이상 절감 목표. 박준혁: 디지털 콘텐츠 제작 비용 전년 대비 25% 절감 KPI |
| 5 | **워크플로우 통합** | 이서연: Notion/Slack/Frame.io 연동 필수. 박준혁: PIM(Bynder)/DAM 연동, 승인 워크플로우 내장 요구 |

### 찬성/지지 포인트
1. **하이브리드 엔진의 상품 정체성 보존**: 기존 AI 도구의 최대 약점(로고 뭉개짐, 색상 변경)을 구조적으로 차단하는 접근은 브랜드 마케터의 가장 큰 우려를 정면으로 해소한다.
2. **크로스 플랫폼 OSMU 전략**: 1번 생성으로 5개 플랫폼 자동 최적화 출력은 제작 시간을 3배 이상 단축하는 구체적 가치.
3. **비용 절감 효과 명확**: PRD에 명시된 ROI 계산은 B2B 의사결정자가 내부 승인을 받기에 충분한 수준.
4. **AI 라벨링 규제 자동 준수**: C2PA 워터마크 자동 삽입, 공정위 광고 표시 자동 삽입 기능은 법무팀 부담을 경감.

### 우려/반대 포인트
1. **MVP에서 브랜드 킷 미지원**: 브랜드 킷이 Phase 2로 분류되어 있어, MVP 시점에서 실질적으로 사용하기 어려움.
2. **배치 처리/API가 Phase 2~3**: 에이전시 세그먼트는 MVP 단계에서 사실상 타겟에서 제외됨.
3. **엔터프라이즈 기능 부재 (Phase 3~4)**: SSO, RBAC, 승인 워크플로우가 늦어져 대기업 도입 지연.
4. **품질 "B+ 수준" 천장 우려**: AI 생성물이 프리미엄 광고 수준에 미달할 우려.
5. **경쟁사 차별화 상실**: 모든 에이전시가 같은 AI 툴을 쓰면 차별화가 어려워짐.

## 2. B2C 고객 관점 (최유진, 장하늘, Sarah, 오성호)

### 핵심 관심사 Top 5

| 순위 | 관심사 | 근거 |
|:----:|--------|------|
| 1 | **극단적 사용 편의성** | 최유진: "캡컷도 어렵게 느낌", 하루 14시간 이상 일하며 영상 편집에 할애할 시간이 물리적으로 없음 |
| 2 | **가격 (월 만 원 이하)** | 최유진: 월 순이익 150~200만 원에서 월 구독료에 매우 민감. 외주 1건 10~20만 원은 과도 |
| 3 | **생성 속도 (60초 이내)** | MVP 핵심 가설: "60초 이내 생성 시 영상 제작 빈도 3배 증가" |
| 4 | **개성/차별화 표현** | 장하늘(인플루언서): "내 채널만의 톤이 유지되어야", 최유진: 핸드메이드 제품의 독특한 감성 표현 필요 |
| 5 | **실제 매출 연결** | 최유진: 월 매출 500만 -> 1,000만 원 돌파 목표. 영상이 실제 구매 전환으로 이어지는지가 핵심 |

### 찬성/지지 포인트
1. **"사진 1장, 버튼 1번, 영상 1개"의 단순함**: 편집 지식 제로에서도 사용 가능한 Level 0 모드.
2. **Starter 플랜 ₩9,900/월**: 외주 대비 99% 절감되는 압도적인 가격 경쟁력.
3. **무료 플랜 월 3건 제공**: 비용 부담 없이 서비스 체험 가능.
4. **멀티플랫폼 자동 출력**: 원클릭으로 3개 플랫폼 규격 자동 대응.
5. **한국어 특화 (카피 + TTS)**: 글로벌 도구 대비 한국 시장 특화 가치.

### 우려/반대 포인트
1. **무료 플랜 제약 과도**: 15초, 워터마크, 1개 플랫폼 제한으로 실질적 가치 체험 부족 우려.
2. **"AI가 만든 티" 우려**: 개인 브랜딩/진정성이 중요한 사용자에게 AI 라벨은 부정적일 수 있음.
3. **스타일 다양성 한계**: MVP 5개 스타일로는 다양한 개성 표현 부족.
4. **도매업체 대량 처리 미지원**: SKU가 많은 도매업체는 MVP 단계에서 사용 불가.
5. **네이버/쿠팡 연동 부재 (MVP)**: 스마트스토어 연동 지연으로 핵심 편의 기능 부재.

## 3. 투자자/경영진 관점

### 핵심 관심사 Top 5

| 순위 | 관심사 | 근거 |
|:----:|--------|------|
| 1 | **시장 규모 & 성장성** | TAM $5~8B, SAM $500M~$1B, CAGR 27.7%. 이커머스 숏폼 영상의 필수화 |
| 2 | **유닛 이코노믹스 건전성** | Gross Margin 65~70%, LTV/CAC >3x 목표, Year 2 BEP |
| 3 | **경쟁 해자 (Moat)** | 빅테크 무료 도구 진출 리스크 vs 크로스 플랫폼 + 한국 네이티브 차별화 |
| 4 | **확장성 (Scalability)** | 한국 -> 글로벌 확장 경로, Year 3 ARR ₩79.8억 목표 |
| 5 | **팀 실행력** | 4~6주 MVP 개발, 마일스톤 기반 펀딩 전략 |

### 찬성/지지 포인트
1. **명확한 시장 공백**: "상품 사진 1장 -> 완성된 영상" 엔드투엔드 솔루션 부재 공략.
2. **PLG 구조의 효율적 성장**: 생성 영상 자체가 마케팅 채널이 되는 구조.
3. **기술 발전이 아군**: AI 모델 품질 향상 및 가격 하락으로 마진 개선 예상.
4. **한국 시장 선점**: 네이버/쿠팡 생태계 특수성으로 글로벌 경쟁사 진입 장벽 존재.
5. **매력적 밸류에이션**: 이커머스 특화 포지셔닝으로 차별화된 투자 스토리.

### 우려/반대 포인트
1. **API 종속 리스크**: 원가의 75%가 외부 API에 집중되어 마진 구조 취약.
2. **무료 티어 비용 부담**: 건당 실비가 발생하는 구조에서 무료 사용자는 비용 부담.
3. **초기 성장 속도**: Year 1 적자 및 초기 매출 규모에 대한 우려.
4. **한국 시장 SOM 한계**: 한국 시장만으로는 VC 수준 성장 스토리에 부족할 수 있음.
5. **빅테크 무료 도구 위협**: Amazon, TikTok 등의 자체 무료 도구 출시 가능성.

## 4. 개발팀/운영팀 관점

### 핵심 관심사 Top 5

| 순위 | 관심사 | 근거 |
|:----:|--------|------|
| 1 | **6주 MVP 타임라인 실현 가능성** | 9개 API 연동 + 오케스트레이션 + 결제를 6주에 완료하는 것은 매우 빠듯함 |
| 2 | **9개 외부 API 동시 의존** | 각 API의 장애, Rate Limit, 정책 변경 리스크 관리 부담 |
| 3 | **60초 이내 생성 시간 달성** | Runway API 응답 시간 등을 고려할 때 60초 목표 달성 어려움 |
| 4 | **비용 관리 (무료 티어)** | 스팸/남용 방지 없이 무료 티어 운영 시 비용 폭증 위험 |
| 5 | **하이브리드 엔진 구현 복잡도** | 자연스러운 합성을 위한 기술적 난이도가 높음 |

### 찬성/지지 포인트
1. **합리적 기술 스택**: Next.js + PostgreSQL + BullMQ + FFmpeg의 검증된 조합.
2. **Build vs Buy 명확**: 핵심 AI는 API 활용, 오케스트레이션은 자체 개발로 효율성 추구.
3. **선제적 폴백 설계**: 3중 폴백 시스템으로 단일 벤더 장애 대응.
4. **비동기 큐 아키텍처**: Rate Limit 대응 및 사용자 경험 최적화.

### 우려/반대 포인트
1. **6주 일정의 비현실성**: 통합 복잡도 및 에러 처리 고려 시 일정 부족.
2. **하이브리드 엔진 품질 불확실**: 자연스러운 합성이 기술적으로 어려울 수 있음.
3. **60초 목표 달성 어려움**: 외부 API 응답 시간에 종속되어 통제 어려움.
4. **무료 티어 남용 방지 미비**: 봇, 중복 계정 등에 대한 방어책 필요.
5. **모니터링 체계 부족**: 복잡한 API 의존성 관리를 위한 모니터링 시스템 부재.
