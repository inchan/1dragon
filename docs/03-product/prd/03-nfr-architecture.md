## 4. 비기능 요구사항

### 4.1 성능 (Performance)

| 지표 | 목표 | 근거 |
|------|------|------|
| **영상 생성 시간** | 90초 이내 (P95) | TTV 목표 120초 중 생성 90초 + 기타 30초 (VISION.md) |
| **이미지 분석 시간** | 5초 이내 | Gemini/Claude Vision API 평균 응답 시간 |

| **영상 생성 동시 처리** | 100건/분 (MVP), 1,000건/분 (Year 2) | 비동기 큐 시스템 기반 |

| 요구사항 | 설명 | 우선순위 |
|---------|------|---------|

| **RBAC** | 역할 기반 접근 제어 (관리자/편집자/뷰어) | Phase 2 |

### 4.3 확장성 (Scalability)

| 요구사항 | 설명 | 근거 |
|---------|------|------|
| **수평 확장** | 컨테이너 기반 오토스케일링 (K8s) | 트래픽 폭증 대응 |
| **비동기 처리** | 영상 생성 요청을 메시지 큐(SQS/RabbitMQ)로 처리 | Rate Limit 대응, 폴백 관리 |

## 6. 제약 사항 & 가정

### 6.1 기술 제약

| 제약 | 상세 | 영향 | 대응 |
|------|------|------|------|
| **I2V 영상 길이** | Runway Gen-4 Turbo: 10초 제한, Hailuo 02: 6초 제한 | 30초 영상은 3개 클립 연결 필요 | FFmpeg 기반 클립 연결, 자연스러운 전환 효과 적용 |
| **프롬프트 민감도** | 동일 프롬프트 재실행 시 품질 편차 20~30% | 생성 결과의 일관성 보장 어려움 | 멀티 모델 폴백 + 자동 QC + 재시도 |
| **AI 환각** | 상품과 다른 영상 생성 확률 0.7~5% | 상품 정체성 훼손 리스크 | 하이브리드 엔진(원본 레이어 합성)으로 구조적 차단 |
| **해상도 한계** | 대부분 I2V 모델 1280x768 생성 | 9:16 세로 영상에 직접 사용 어려움 | 합성 파이프라인에서 세로 영상 전용 처리 |
| **한국어 TTS 감정 표현** | Google Cloud TTS: 기본 음성만 지원 | 표현력 있는 내레이션 한계 | Typecast(한국어 감정 TTS) 채택 |
| **오디오-비주얼 동기화** | TTS + BGM + 영상 별도 생성 | 싱크 맞추기 복잡도 | FFmpeg 기반 정밀 싱크 파이프라인 |

### 6.2 비즈니스 제약

| 제약 | 상세 | 대응 |
|------|------|------|
| **초기 자금** | Pre-Seed 3억 원 (6개월 Runway) | 4~6주 MVP 출시, 빠른 PMF 검증 |
| **팀 규모** | Phase 1: 6~8명 | 핵심 기능 집중, API-first 아키텍처로 개발 효율화 |
| **무료 사용자 비용** | 무료 3건/월 x 무료 사용자 수 = PLG 투자 비용 | 무료 영상은 Hailuo(건당 364원)로 비용 억제 |
| **API 비용 변동** | I2V API 가격 인상 가능성 | 멀티 벤더 + 볼륨 디스카운트 계약 + 자체 호스팅 로드맵 |
| **한국 시장 한정 (MVP)** | 글로벌 확장은 Phase 2 이후 | 한국 시장 PMF 확보 후 점진적 확장 |

### 6.3 주요 가정 (검증 필요 항목 포함)

| # | 가정 | 검증 방법 | 리스크 |
|---|------|----------|--------|
| A1 | 상품 사진 1장으로 생성한 15초 영상이 수동 제작 영상 대비 70% 이상의 CTR을 달성한다 | 베타 유저 50명 A/B 테스트 (Beta 4주차) | 높음 |
| A2 | 1인 셀러가 첫 영상을 60초 이내에 생성하면 주간 영상 제작 빈도가 3배 이상 증가한다 | 코호트 분석 (MVP 4주차) | 중간 |
| A3 | "Made with 1Dragon" 워터마크 포함 영상의 K-factor가 0.3 이상이다 | UTM + 레퍼럴 코드 추적 (MVP 8주차) | 중간 |
| A4 | 무료 사용자의 유료 전환율이 B2C 2% 이상이다 | 크레딧 소진 후 72시간 내 전환율 추적 (MVP 12주차) | 높음 |
| A5 | 네이버 스마트스토어 연동 시 D30 리텐션이 미연동 대비 2배 이상이다 | 코호트 비교 (Phase 2 시작 시) | 중간 |
| A6 | 하이브리드 엔진이 상품 정체성(로고, 색상, 텍스처)을 100% 보존한다 | QC 자동 검증 + 사용자 피드백 | 높음 |
| A7 | 영상 1건 원가가 옵션 C 기준 $0.93 이하를 유지한다 | API 비용 모니터링 | 중간 |
| A8 | AI 생성 콘텐츠 라벨이 광고 CTR에 유의미한 부정적 영향을 주지 않는다 | A/B 테스트 (라벨 유/무 비교) | 낮음 |
| A9 | 한국 1인 셀러(40~55만)의 5~10%가 디지털 영상 도구 얼리어답터이다 | 웨이트리스트 + MVP 초기 가입 데이터 | 중간 |
| A10 | AI API 비용이 연 30% 이상 하락한다 (오픈소스 모델 성장 + 경쟁 심화) | 분기별 API 가격 벤치마크 | 낮음 |

## 8. 릴리즈 계획

### 8.1 Phase 1 (MVP): 핵심 기능 -- 4~6주 개발

**목표:** "상품 사진 1장 -> 15~30초 숏폼 영상 2분 이내 자동 생성" 핵심 가치 검증

**기간:** M1~M3 (개발 4~6주 + 베타 테스트 2~4주)

| 기능 | 상세 | 기술 스택 |
|------|------|----------|
| 상품 사진 업로드 | JPEG/PNG, 1~5장, 모바일/웹 | Next.js, S3 |
| AI 이미지 분석 | 카테고리, 속성 추출 | Claude Vision API |
| 배경 자동 제거 | 1초 이내 처리 | Remove.bg API |
| 이미지 향상 | 업스케일링, 밝기 보정 | Real-ESRGAN (자체) |
| 원클릭 영상 생성 | 하이브리드 엔진, 90초 이내 | Runway Gen-4 Turbo + FFmpeg |
| AI 카피라이팅 | 한국어 마케팅 카피 | GPT-4o API |
| 자동 BGM 매칭 | 기본 라이브러리 20곡 | 라이선스 확보된 음원 |
| 자동 자막 생성 | 한국어 WER 4% 이하 | Deepgram API |
| 스타일/템플릿 | 기본 5개 (Free), 50+ (Starter) | 자체 템플릿 시스템 |
| 멀티플랫폼 출력 | TikTok/Shorts/Reels/클립/쿠팡 | FFmpeg 리사이징 |
| 소셜 로그인 | 카카오/Google/Apple | OAuth 2.0 |
| Freemium 구독 | Free(3건)/Starter(30건) | Stripe + 토스페이먼츠 |
| AI 라벨 삽입 | C2PA 워터마크, 메타데이터 | C2PA SDK |
| 멀티 모델 폴백 | Runway -> Hailuo -> Kling | 비동기 큐 + 라우팅 |

**팀 구성:** 6~8명 (풀스택 2, AI/ML 1, 디자이너 1, PM 1, 그로스 1, 콘텐츠 1)
