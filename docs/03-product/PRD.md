# 1Dragon PRD (Product Requirements Document)

> **작성일:** 2026-02-09
> **버전:** v1.0
> **기반 문서:** Phase 1 리서치 (시장/기술/사용자 조사) + Phase 2 전략 (비전/비즈니스 모델/GTM)
> **문서 상태:** 초안 -- 제품팀 리뷰 대기

---

## 문서 구조

본 PRD는 가독성과 유지보수를 위해 3개의 하위 문서로 분할되었습니다.

---

### 1. 에픽 & 사용자 스토리

> 제품 비전/미션, 목표 사용자 7개 페르소나, 핵심 문제 정의, 8개 에픽(E1~E8)과 에픽별 사용자 스토리 25개를 포함합니다. 각 사용자 스토리는 "As a ~ I want ~ so that ~" 형식과 인수 조건(Acceptance Criteria)을 정의합니다.

[상세 보기](prd/01-epics-stories.md)

---

### 2. 기능 요구사항

> MoSCoW 우선순위 매트릭스로 45개 기능(Must Have 16개, Should Have 11개, Could Have 12개, Won't Have 6개)을 분류합니다. 성공 지표(North Star Metric, AARRR별 KPI, MVP 성공 기준 8개 항목)를 정의합니다.

[상세 보기](prd/02-functional-requirements.md)

---

### 3. 비기능 요구사항 & 아키텍처

> 성능/보안/확장성/가용성/국제화/접근성 비기능 요구사항, 기술 제약 6개와 비즈니스 제약 5개, 검증 필요 가정 10개, 외부 API 의존성 12개와 플랫폼 연동 7개, 4단계 릴리즈 계획(Phase 1~4), 오픈 이슈 10개를 정의합니다.

[상세 보기](prd/03-nfr-architecture.md)

---

> - **시니어 프로덕트 매니저**: 6개 입력 문서(시장/기술/사용자 조사 + 비전/비즈니스모델/GTM 전략)의 데이터를 통합하여, 8개 에픽과 45개 기능 요구사항을 구조화하고 MoSCoW 우선순위를 배정했습니다.
