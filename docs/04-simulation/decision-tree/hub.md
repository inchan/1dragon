# 의사결정 트리 분석 (Decision Tree) Hub

> **작성일:** 2026-02-09
> **분석 기간:** Week 0 (MVP 출시) ~ Month 6 (런웨이 결정)
> **방법론:** Tree of Thoughts — 각 분기점에서 복수 경로 탐색 및 시나리오 분석

## Executive Summary

MVP 출시 후 6개월간 발생할 수 있는 주요 분기점을 시뮬레이션하여 3가지 핵심 경로(Best, Most Likely, Worst)와 1가지 숨겨진 위험 경로(Hidden Danger)를 도출했습니다. 가장 가능성 높은 "Most Likely Path"를 기준으로 자원 배분 및 마일스톤을 설정하고, 각 분기점별 Go/No-Go 체크리스트와 피봇 트리거를 마련했습니다.

## 목차 (Navigation)

### 1. [경로 분석 (Path Analysis)](01-analysis.md)
   - 전체 의사결정 트리 다이어그램
   - 4대 주요 분기점 상세 분석
     1. **개발 완료도 (Week 6)**: MVP 완성 여부 (Path A/B/C)
     2. **초기 사용자 반응 (Week 8~14)**: 성공/보통/실패 시나리오
     3. **유료 전환 (Month 2~3)**: 고전환/저전환/전환실패 시나리오
     4. **자원 & 런웨이 (Month 4~6)**: 투자/부트스트래핑/피봇/셧다운 결정

### 2. [핵심 시나리오 (Key Scenarios)](02-scenarios.md)
   - **Best Case**: 6주 완성 → 성공 → 고전환 → 투자 유치 (확률 ~2%)
   - **Most Likely**: 6~8주 완성 → 보통 → 저전환 → 부트스트래핑 (확률 ~23%)
   - **Worst Case**: 기술 장애 → 피봇 실패 → 셧다운 (확률 ~3%)
   - **Hidden Danger**: 성공적 반응이나 수익화 실패로 자금 소진
   - **Pivot Paths**: 실패 시 전환 가능한 4가지 대안 (P-A~D)

### 3. [가이드 & 리스크 (Guide & Risk Matrix)](03-guide.md)
   - 시점별 Go/No-Go 체크리스트 (Week 3, 6, 12, Month 4)
   - 피봇 트리거 대시보드 (T-1 ~ T-6)
   - 종합 리스크 매트릭스 및 대응 전략
   - 시나리오별 자원 배분 계획

### 핵심 권고사항 5가지

1. **Week 3 마일스톤이 결정적**: "사진 1장 -> 15초 영상" E2E 성공 여부가 전체 운명 결정.
2. **Hidden Path 방어 필수**: Free/Paid 가치 격차를 MVP 설계부터 반영하여 "바이럴 함정" 회피.
3. **피봇은 전략이다**: Month 3에 공식 피봇 리뷰 세션 설정.
4. **생존 임계선 인지**: MAU 5,000 + 유료 100명 + MRR ₩100만을 부트스트래핑 최소 조건으로 관리.
5. **Most Likely Path 기준 실행**: Best Case가 아닌 현실적 경로(8주 완성, 전환율 2.5%)를 기준으로 계획 수립.
