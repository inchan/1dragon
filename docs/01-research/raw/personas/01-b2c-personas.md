| 항목 | 내용 |
|------|------|
| **직업/소속** | 핸드메이드 악세서리 스마트스토어 "유진의공방" 대표 (1인) |
| **회사 규모** | 1인 사업자, 월매출 약 500만 원 |
| **디지털 리터러시** | 중 -- 스마트폰 편집 앱 활용, PC 편집 도구는 미숙 |

#### 배경과 일상
대학에서 공예디자인을 전공하고 2년간 악세서리 쇼핑몰에서 MD로 일한 뒤 독립. 집에서 직접 제작/촬영/포장/배송/CS까지 모든 과정을 혼자 처리한다. 오전에 전날 주문 포장/발송, 오후에 새 상품 제작, 저녁에 상품 촬영과 상세페이지 작업. 인스타그램(팔로워 4,800)으로 고객 소통하며, 최근 릴스의 노출 효과를 체감해 영상 콘텐츠를 시도 중이나 시간이 절대적으로 부족하다.

#### 핵심 목표
- 월매출 500만 원 -> **1,000만 원** 달성 (6개월 내)
- 인스타그램 릴스 주 **3회 이상** 게시 유지 (현재 월 2~3회)
- 신규 유입 채널로 **틱톡** 진출 (현재 계정 없음)

#### 주요 고충 Top 3
1. **절대적 시간 부족**: 제작/배송/CS에 하루 10시간 소진. 영상 촬영/편집에 할애할 시간이 주 2~3시간뿐
2. **기술적 장벽**: 영상 편집 경험이 거의 없음. CapCut 템플릿을 써도 "내 상품에 맞는 느낌"을 못 만들겠음
3. **예산 제약**: 월 순이익 약 150만 원. 영상 외주(건당 30~50만 원)는 엄두 못 냄. 도구 구독도 월 2만 원 이상이면 고민

#### 현재 영상 제작 워크플로우
```
[촬영] 아이폰 13 + 자연광 (책상 위 세팅)
  -> [편집] 아이폰 CapCut 앱 (템플릿 사용)
  -> [자막] CapCut 자동자막 (정확도 70%, 수동 보정)
  -> [업로드] 인스타그램 앱에서 직접 업로드
  -> [해시태그] 수동 입력 (매번 비슷한 30개)
```
소요시간: 영상 1개당 약 **2~3시간** (촬영 40min + 편집 1h + 자막/업로드 30min)

#### 월 영상 마케팅 예산
- 영상 제작: **0원** (본인 직접)
- 도구 구독: **약 1.3만 원** (Canva Pro)
- 광고: **10~20만 원/월** (인스타그램 게시물 부스트)
- **총 마케팅 예산: 약 12~22만 원/월**

#### 사용 중인 도구
| 카테고리 | 도구 |
|----------|------|
| 영상 편집 | CapCut (무료, 모바일) |
| 이미지 편집 | Canva Pro, 아이폰 기본 편집 |
| 쇼핑몰 | 네이버 스마트스토어 |
| SNS | Instagram, 카카오톡 채널 |
| 배송 | 스마트택배, 편의점 택배 |
| 고객 관리 | 네이버 톡톡, 인스타 DM |

#### 서비스에 대한 기대와 우려
| 기대 | 우려 |
|------|------|
| 상품 사진만 넣으면 영상 완성 -- 영상 편집 기술 불필요 | 핸드메이드 감성(따뜻함, 수작업 느낌)을 AI가 살릴 수 있을까 |
| 릴스+쇼츠+틱톡용 한번에 생성 -> 새 채널 진출 가능 | 무료 or 월 1~2만 원 이하가 아니면 부담 |
| 스마트폰에서 바로 사용 가능한 UX | 핸드메이드 특유의 디테일(실 꿰매기, 비즈 배치)이 영상에 잘 담기는지 |
| 해시태그/캡션도 자동 생성되면 완벽 | 내 상품이 AI 학습 데이터로 쓰여서 비슷한 상품이 양산되는 건 아닌지 |

#### 의사결정 기준
1. **가격**: 무료 플랜 또는 월 **1~2만 원** 이하. 영상 편수 제한이 있다면 월 10편 이상 가능해야
2. **사용 편의성**: PC 없이 **스마트폰만으로** 완결되는 워크플로우
3. **핸드메이드 감성**: 템플릿이 "대량생산 쇼핑몰" 느낌이면 안 됨. 따뜻하고 아기자기한 무드 옵션
4. **즉시 체감**: 가입 후 **5분 이내에** 첫 영상 결과물을 볼 수 있어야 이탈하지 않음
