## 페르소나 1

### 김민수 (32세) -- 중소 패션 브랜드 마케팅 담당자

| 항목 | 내용 |
|------|------|
| **직업/소속** | 패션 브랜드 "어반블랑" 마케팅 매니저 (정직원) |
| **회사 규모** | 직원 15명, 연매출 18억 원 |
| **디지털 리터러시** | 중상 -- Canva/CapCut은 능숙, Premiere는 기초 수준 |

#### 배경과 일상
대학에서 경영학을 전공하고 대행사에서 3년 근무 후, 브랜드 인하우스로 이직. 혼자서 SNS 계정 운영(인스타그램 1.2만 팔로워, 틱톡 3,000), 네이버 스마트스토어 상세페이지, 유료 광고 집행, 인플루언서 시딩까지 전부 담당한다. 시즌 전환기(S/S, F/W)에는 신상품 30~40개의 룩북 촬영과 콘텐츠 제작이 동시에 몰린다. 오전에 전날 광고 성과를 확인하고, 오후에 촬영/편집, 저녁에 예약 게시--이 사이클이 반복된다.

#### 핵심 목표
- 시즌당 신상품 30~40개의 숏폼 영상을 **출시 2주 내**에 전부 게시
- 인스타그램 릴스 도달률을 현재 2.1%에서 **4% 이상**으로 끌어올리기
- 영상 콘텐츠 비중을 전체 게시물의 30% -> **60%**로 확대

#### 주요 고충 Top 3
1. **시간 부족**: 상품 1개당 영상 촬영~편집~자막에 평균 3~4시간 소요. 30개면 90~120시간인데, 다른 업무도 병행해야 함
2. **플랫폼별 최적화**: 틱톡(9:16, 15~30초), 릴스(9:16, 30~60초), 쇼츠(9:16, 60초)의 미묘한 차이를 각각 맞추는 반복 작업
3. **디자인 퀄리티 한계**: 본인이 만든 영상과 경쟁 브랜드(무신사 입점 상위 브랜드)의 영상 사이 퀄리티 격차 체감

#### 현재 영상 제작 워크플로우
```
[촬영] 아이폰 15 Pro + 삼각대 + 링라이트
  -> [편집] CapCut (무료) / 가끔 Canva Video
  -> [자막/효과] CapCut 자동자막 + 수동 보정
  -> [리사이징] 플랫폼별 비율 수동 조정
  -> [업로드] 각 플랫폼 앱에서 직접 업로드
  -> [광고] Meta Ads Manager + TikTok Ads
```
소요시간: 상품 1개당 약 3~4시간 (촬영 1h + 편집 1.5h + 업로드/최적화 0.5~1h)

#### 월 영상 마케팅 예산
- 영상 제작: **0원** (본인 직접 제작) ~ 비수기 외주 시 건당 30~50만 원
- 광고 집행: **150~250만 원/월** (Meta 60%, TikTok 30%, 네이버 10%)
- **총 마케팅 예산: 약 200~300만 원/월**

#### 사용 중인 도구
| 카테고리 | 도구 |
|----------|------|
| 영상 편집 | CapCut (무료), Canva Pro (13,000원/월) |
| 이미지 편집 | Photoshop (회사 라이선스), Canva |
| SNS 관리 | Later (20,000원/월), 네이티브 앱 |
| 광고 | Meta Ads Manager, TikTok Ads Manager |
| 분석 | Instagram Insights, TikTok Analytics, Google Analytics |
| 커뮤니케이션 | Slack, Notion |

#### 서비스에 대한 기대와 우려
| 기대 | 우려 |
|------|------|
| 상품 사진만 올리면 3개 플랫폼용 영상이 한번에 나오는 것 | "AI 느낌" 나는 영상이면 브랜드 이미지 훼손 |
| 시즌 신상품 30개를 하루 안에 일괄 처리 | 우리 브랜드 톤앤매너(미니멀/뉴트럴)를 반영 못할 수도 |
| 편집 시간 80% 이상 절감 | 대표님이 "직접 찍는 게 더 진정성 있다"고 반대할 가능성 |
| 월 5~10만 원 수준의 합리적 가격 | 퀄리티가 외주(건당 50만 원) 수준은 되어야 의미 있음 |

#### 의사결정 기준
1. **시간 절감 효과**: 상품당 편집 시간이 30분 이내로 줄어야 도입 가치 있음
2. **브랜드 커스터마이징**: 폰트/컬러/로고/트랜지션을 브랜드 가이드에 맞게 설정 가능한지
3. **비용 대비 퀄리티**: 월 10만 원 이하면 시도, 20만 원 이상이면 외주 대비 ROI 비교 필요
4. **팀 내 설득 용이성**: 대표에게 Before/After 비교 영상을 보여줄 수 있는 무료 체험 필수

## 페르소나 2

### 이서연 (38세) -- 마케팅 에이전시 디렉터

| 항목 | 내용 |
|------|------|
| **직업/소속** | 디지털 마케팅 에이전시 "미디어랩M" 콘텐츠 디렉터 |
| **회사 규모** | 직원 30명, 동시 관리 클라이언트 12개 |
| **디지털 리터러시** | 상 -- Premiere/After Effects 실무 가능, AI 도구 얼리어답터 |

#### 배경과 일상
광고대행사에서 10년 경력 후, 소규모 에이전시로 이직해 콘텐츠팀(6명) 리드. 클라이언트당 월 4~8편의 숏폼 영상을 제작/납품한다. 주니어 디자이너 3명이 제작하고 서연이 디렉션/품질관리/클라이언트 커뮤니케이션을 담당. 월요일에 주간 콘텐츠 캘린더를 정리하고, 수요일까지 초안 피드백, 금요일까지 최종 납품하는 사이클. 12개 클라이언트의 브랜드 가이드를 동시에 머리에 넣고 있어야 한다.

#### 핵심 목표
- 클라이언트당 납품 리드타임을 현재 **5영업일 -> 2영업일**로 단축
- 팀 인당 월 처리 클라이언트 수를 **2개 -> 4개**로 확대 (매출 2배)
- 숏폼 영상 서비스를 신규 수익원으로 패키지화 (현재 이미지 콘텐츠 중심)

#### 주요 고충 Top 3
1. **인력 병목**: 클라이언트 증가 -> 인원 충원 -> 고정비 증가의 악순환. 주니어 온보딩에 1~2개월 소요
2. **브랜드 일관성 관리**: 12개 클라이언트 각각의 톤앤매너/금칙어/로고 가이드를 실수 없이 적용하는 것이 최대 리스크
3. **수익성 압박**: 숏폼 영상 건당 단가 80~150만 원인데, 제작 원가(인건비+도구비)가 50~70%를 차지. 마진이 계속 줄고 있음

#### 현재 영상 제작 워크플로우
```
[기획] 클라이언트 브리프 -> Notion 템플릿에 콘텐츠 플랜 작성
  -> [소스 수집] 클라이언트 제공 상품 사진/영상 소스
  -> [편집] Premiere Pro + After Effects (주니어), CapCut (급한 건)
  -> [내부 리뷰] Frame.io에서 디렉터 피드백 (평균 2~3회 수정)
  -> [클라이언트 리뷰] Frame.io 링크 공유 -> 피드백 반영
  -> [납품] 플랫폼별 파일 + 캡션 텍스트 + 해시태그 세트
  -> [리포트] 월간 성과 리포트 (노출/도달/전환)
```
소요시간: 클라이언트 1건당 평균 8~12시간 (기획 2h + 제작 4~6h + 리뷰 2~4h)

#### 월 영상 마케팅 예산 (에이전시 운영 관점)
- 도구 비용: **약 120만 원/월** (Adobe CC 6 라이선스 396,000원 + Frame.io 150,000원 + 스톡영상/음원 300,000원 + 기타)
- 인건비 (콘텐츠팀 6명): **약 2,400만 원/월**
- 클라이언트 청구 기준: 월 리테이너 200~500만 원/클라이언트

#### 사용 중인 도구
| 카테고리 | 도구 |
|----------|------|
| 영상 편집 | Adobe Premiere Pro, After Effects, CapCut |
| 협업/리뷰 | Frame.io, Notion, Slack |
| 프로젝트 관리 | Notion (칸반보드), Google Sheets |
| 스톡 소스 | Artgrid, Epidemic Sound, Envato Elements |
| 리포팅 | Google Data Studio, Socialbakers |
| 광고 집행 | Meta Business Suite, TikTok Business Center |

#### 서비스에 대한 기대와 우려
| 기대 | 우려 |
|------|------|
| 초안 자동 생성으로 주니어 제작시간 70% 절감 | 클라이언트가 "AI로 만들었다"는 걸 알면 단가 인하 압박 |
| 12개 브랜드 프리셋 저장 -> 브랜드 일관성 자동 보장 | 세밀한 디렉션(특정 컷 순서, 감성 무드)이 안 될 수도 |
| B2B API/대시보드 -> 워크플로우에 통합 | 클라이언트별 산출물 관리/권한 분리가 안 되면 도입 불가 |
| 신규 서비스 패키지: "AI 숏폼 월정액" 상품화 가능 | 에이전시 존재 가치가 희석될까 하는 장기적 우려 |

#### 의사결정 기준
1. **팀 워크플로우 통합**: API 제공, 화이트라벨(자사 브랜드로 납품), 다중 클라이언트 관리 기능
2. **수정 용이성**: AI 초안에서 컷 순서 변경/텍스트 수정/BGM 교체가 가능해야 함
3. **가격 구조**: 영상 편수 기반 종량제 또는 클라이언트당 서브스크립션. 월 30~50만 원/클라이언트 이내
4. **보안/NDA**: 클라이언트 미공개 상품 이미지가 AI 학습에 사용되지 않는다는 보장

## 페르소나 3

### 박준혁 (45세) -- 화장품 대기업 마케팅팀 리더

| 항목 | 내용 |
|------|------|
| **직업/소속** | 코스메틱 기업 "아모르뷰티" (가칭) 디지털마케팅팀 팀장 |
| **회사 규모** | 직원 800명, 마케팅팀 25명, 연매출 3,000억 원 |
| **디지털 리터러시** | 중 -- 전략/KPI 관리 중심, 직접 제작은 하지 않음 |

#### 배경과 일상
P&G 출신으로 전통적 마케팅(TV/잡지) 경험이 풍부하며, 3년 전 디지털마케팅팀으로 전환. SKU 약 350개, 시즌마다 20~30개 신제품 출시. 팀 내 숏폼 전담 인력 3명, 외주 프로덕션 2곳과 협업. 본인은 예산 승인, KPI 설정, 캠페인 전략 수립이 주 업무. 매주 월요일 경영진 보고에서 "숏폼 ROAS"를 설명해야 하는 압박이 있다.

#### 핵심 목표
- 전 SKU(350개)에 대해 **숏폼 영상 커버리지 100%** 달성 (현재 약 30%)
- 신제품 출시 시 **D-Day 동시 3플랫폼 영상 게시** 체계 구축
- 숏폼 캠페인 ROAS를 현재 **2.1 -> 3.5 이상**으로 개선

#### 주요 고충 Top 3
1. **SKU 커버리지 한계**: 350개 SKU 중 영상이 있는 건 약 100개. 나머지는 예산/인력 부족으로 이미지 광고에 의존
2. **승인 프로세스 지연**: 법무팀(성분 표기)/브랜드팀(디자인 가이드)/경영진 3단계 승인에 2~3주 소요. 트렌드를 놓침
3. **성과 측정 어려움**: 3개 플랫폼 x 다수 SKU의 영상 성과를 통합 분석하는 시스템이 없음. 수작업 엑셀 취합

#### 현재 영상 제작 워크플로우
```
[기획] 마케팅팀 전략 -> 대행사 브리프 전달 (Notion/이메일)
  -> [제작 의뢰] 외주 프로덕션 A (프리미엄), B (볼륨) 분리
  -> [제작] 프로덕션 자체 촬영/편집 (2~3주)
  -> [내부 리뷰] 브랜드팀 검수 -> 법무팀 성분/문구 검수
  -> [수정] 평균 2~4회 수정 사이클
  -> [배포] 인하우스팀이 플랫폼별 업로드 + 광고 세팅
  -> [리포팅] 월간 대시보드 (Tableau)
```
소요시간: 기획~게시까지 평균 **3~4주**, 급한 건 1.5주 (추가 비용 발생)

#### 월 영상 마케팅 예산
- 영상 제작 외주비: **2,000~3,000만 원/월**
- 광고 집행비: **5,000~8,000만 원/월** (Meta 40%, TikTok 30%, YouTube 20%, 네이버 10%)
- 도구/플랫폼: **약 300만 원/월** (Adobe CC, Tableau, Sprinklr 등)
- **총 디지털 마케팅 예산: 약 8,000만~1.2억 원/월**

#### 사용 중인 도구
| 카테고리 | 도구 |
|----------|------|
| 영상 (외주) | 외주 프로덕션 2곳 |
| 프로젝트 관리 | Jira, Confluence, Notion |
| 광고 | Meta Business Suite, TikTok Business Center, Google Ads |
| 분석 | Tableau, Sprinklr, Google Analytics 4 |
| DAM | Bynder (디지털 에셋 관리) |
| 커뮤니케이션 | MS Teams, Outlook |

#### 서비스에 대한 기대와 우려
| 기대 | 우려 |
|------|------|
| 350개 SKU 전수 영상화 가능 -> 롱테일 SKU도 커버 | 대기업 보안 정책(클라우드 업로드 제한, 미출시 제품 보안) |
| 외주비 50% 이상 절감 -> 예산을 광고 집행에 재배분 | 법무팀 승인 절차와의 연동 -- AI 생성 문구의 법적 검토 필요 |
| 신제품 D-Day 동시 게시 가능 | "스타트업 MVP"의 안정성/SLA -- 대기업 기준 99.9% 가동률 필요 |
| A/B 테스트 자동화 (같은 상품, 다른 무드의 영상 5개 생성) | 기존 프로덕션과의 관계 관리. 갑자기 외주를 끊기 어려움 |

## 페르소나 7

### 오성호 (42세) -- 도매/유통업체 운영자

| 항목 | 내용 |
|------|------|
| **직업/소속** | 의류 도매업체 "성호무역" 대표 |
| **회사 규모** | 직원 8명 (물류 4명, 영업 2명, 관리 2명), 연매출 약 25억 원 |
| **디지털 리터러시** | 하~중 -- 엑셀/카카오톡 중심, 영상 편집 경험 전무 |

#### 배경과 일상
동대문 의류 도매 15년 경력. 오프라인 도매 중심이었으나 코로나 이후 온라인 B2B 채널(도매꾹, 셀러허브)과 네이버 스마트스토어(B2C) 동시 운영으로 전환. SKU 약 3,000개이지만 대부분 상품 사진만 있고, 영상은 전무. 최근 경쟁 도매업체들이 인스타 릴스/틱톡으로 소매 셀러(B2B2C)에게 상품을 노출하는 트렌드를 목격하고 "우리도 해야 하는데..."라는 위기감.

#### 핵심 목표
- SKU 3,000개 중 **매출 상위 500개**라도 숏폼 영상 확보
- 소매 셀러(거래처)에게 **영상 소스 제공** -> 거래처 이탈 방지 + 신규 거래처 유입
- B2C 채널(스마트스토어) 매출 비중을 현재 15% -> **30%**로 확대

#### 주요 고충 Top 3
1. **압도적인 SKU 수량**: 3,000개 SKU에 영상을 만든다는 것 자체가 기존 방식으로는 불가능. 외주 시 건당 30만 원 x 500개 = 1.5억 원
2. **영상 제작 역량 제로**: 사내에 영상을 만들 수 있는 사람이 없음. 본인도 CapCut이 뭔지 모름. "사진을 넣으면 영상이 나온다"가 유일한 해법
3. **상품 회전율**: 패션 도매 특성상 상품 수명이 2~4주. 영상 제작에 1주일 걸리면 이미 재고가 소진되거나 다음 시즌으로 넘어감

#### 현재 영상 제작 워크플로우
```
[현재 워크플로우 = 없음]
- 상품 사진: 스튜디오에서 대량 촬영 (1일 100~200개 SKU)
- 사진 보정: 외주 보정업체 (건당 500~1,000원)
- 상세페이지: 사진 + 텍스트 조합 (직원이 스마트스토어에 수동 등록)
- 영상: 없음. 경쟁사가 하는 걸 보고만 있는 상태
```
영상 관련 소요시간: **0시간** (아예 안 하고 있음)

#### 월 영상 마케팅 예산
- 현재 영상 예산: **0원**
- 상품 촬영비: **약 200만 원/월** (스튜디오 렌탈 + 포토그래퍼)
- 사진 보정 외주: **약 50만 원/월**
- 온라인 광고: **약 100만 원/월** (네이버 쇼핑 검색광고 위주)
- **총 마케팅 예산: 약 350만 원/월** (영상 전환 시 추가 50~100만 원 가용)

#### 의사결정 기준

2. **극단적 사용 편의성**: 회원가입 -> 사진 업로드 -> 영상 다운로드. **3단계 이내**
3. **가격**: SKU당 단가 기준 **1,000~3,000원** 이하. 또는 월정액 30~50만 원 (무제한에 가까운 편수)
4. **속도**: 사진 업로드 후 **5분 이내** 영상 완성 (일 100개 = 하루 안에 처리 가능해야)
