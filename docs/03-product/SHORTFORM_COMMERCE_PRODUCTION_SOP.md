# 숏폼 커머스 실전 제작 SOP (의류/운동화 중심)

> 작성일: 2026-02-19  
> 목적: 정지 이미지 모션 수준을 넘어서, **실착/실착화 기반 행동 증명 + 스토리 기반 전환**을 달성하는 실행 표준

## 0. 입력값 기본 가정 (입력 미제공 시)

- 상품군: 의류 + 운동화
- 타겟 페르소나: 20~34세, 남녀, 출퇴근+주말 액티브 라이프스타일
- 브랜드 톤: 스트릿 + 미니멀
- 보유 에셋: 누끼 이미지, 디테일 컷, 라이프스타일 컷, 로고
- 플랫폼: TikTok / YouTube Shorts / Instagram Reels
- KPI 목표(초기): CTR 1.8%+, 3초 유지율 70%+, 15초 완주율 28%+, 장바구니율 4%+, 구매전환 1.5%+

---

## 1) 핵심 결론 (5~7줄)

1. 성과형 숏폼은 정지 이미지 모션이 아니라 **사람의 행동 안에서 제품 효용을 증명**해야 한다.
2. 영상 구조는 반드시 **Hook(0~2초) → 사용 맥락 → 전환 포인트 → CTA(마지막 2초)**로 고정한다.
3. 실전 운영 단위는 1개 마스터가 아니라 **Hook 3종 × CTA 2종 = 6셀** 파생본이다.
4. 저성과의 핵심 원인은 손/발 왜곡, 로고 변형, 물리 어색함이므로 QC 게이트를 강제한다.
5. 7일 스프린트 기준으로 Day 1~3 제작, Day 4~5 후반, Day 6~7 집행+개선이 가장 효율적이다.
6. 판단은 감이 아니라 지표로 한다: 72시간 1차 판정, 7일 2차 판정으로 승자 조합을 확장한다.

## 2) 실전 제작 SOP

| 단계명 | 목적 | 입력물 | 실행 방법 | 산출물 | 품질 체크 기준 |
|---|---|---|---|---|---|
| 1. 조사(Research) | 플랫폼/정책/레퍼런스 확인 | 광고 가이드, 경쟁소재 | 플랫폼 제약(길이/비율/안전영역), 카테고리 벤치마크 조사 | 조사 메모 v1 | 정책 충돌 0건 |
| 2. 탐색(Explore) | 사용 맥락 수집 | 상품 USP, 리뷰, CS | 페르소나별 TPO 3개(출근/데이트/운동) 도출 | 인사이트 노트 | 문제-상황-해결 흐름 명확 |
| 3. 분석(Analyze) | 설득 포인트 우선순위 | 조사/탐색 결과 | 훅 포인트, 반박 포인트, 전환 포인트 정의 | 메시지 맵 | 핵심 메시지 1문장 설명 가능 |
| 4. 계획(Plan) | 촬영/편집 설계 확정 | 메시지 맵, 에셋 | 15s/30s 샷리스트, 콜시트, 역할 분담, 일정 잠금 | 제작 플랜 v1 | 일정/역할/산출물 누락 없음 |
| 5. 구현(Implement) | 실사 중심 소스 제작 | 모델, 제품, 로케이션 | A롤(행동), B롤(디테일), C롤(리액션) 분리 촬영 후 편집 | 마스터 v1 + 6셀 | 행동 컷 비중 70%+ |
| 6. 테스트(Test) | 성과 가설 검증 | 파생본 6셀, 예산 | 셀당 최소 1,000노출 집행, KPI 계측 | 72h 테스트 리포트 | 지표 기준 미달 셀 식별 |
| 7. 리뷰(Review) | 개선/확장 결정 | 테스트 리포트 | 승자 조합 확장, 저성과 셀 폐기/교체, v2 리컷 | 개선본 v2 | KPI 상승 또는 실패원인 명확 |

## 3) 상품군별 스토리 템플릿 (3개 이상)

### 3-1. 의류 템플릿

1. **착장 전/후 변환형**  
   - Hook: "출근룩, 왜 늘 핏이 애매하지?"  
   - 맥락: 기본룩(전) → 동일 인물/동일 장소(후)  
   - 전환 포인트: 어깨선/기장/옆태 비교  
   - CTA: "오늘 코디 저장하고 바로 구매"

2. **TPO 전환형 (출근→데이트)**  
   - Hook: "퇴근 후 약속, 갈아입을 시간 없음"  
   - 맥락: 동일 상의/신발 + 아우터/액세서리 교체  
   - 전환 포인트: 1룩 2상황 소화  
   - CTA: "하루 2룩 조합 보러가기"

3. **실루엣 유지 검증형**  
   - Hook: "걷고 앉으면 핏 무너지는 옷, 아직도 입나요?"  
   - 맥락: 걷기/앉기/팔올리기 연속 행동  
   - 전환 포인트: 동작 중 라인 유지  
   - CTA: "체형별 핏 추천 확인"

### 3-2. 운동화 템플릿

1. **착화 첫인상형**  
   - Hook: "신자마자 편한지 3초면 압니다"  
   - 맥락: 착화 → 첫 걸음 → 표정 변화  
   - 전환 포인트: 뒤꿈치 고정/발목 안정  
   - CTA: "사이즈 가이드로 바로 선택"

2. **러닝/점프/턴 동작형**  
   - Hook: "코너에서 밀리면 게임 끝"  
   - 맥락: 러닝 → 급턴 → 점프 착지  
   - 전환 포인트: 접지/쿠셔닝 슬로모션  
   - CTA: "움직임 많은 날 이 한 켤레"

3. **장시간 착화 비교형**  
   - Hook: "오후 4시면 발이 먼저 지친다"  
   - 맥락: 출근-이동-퇴근 루틴 압축  
   - 전환 포인트: 전/후 피로도 코멘트  
   - CTA: "하루 종일 신는 신발로 교체"

### 3-3. 뷰티 템플릿

1. **문제해결형**: 번들/다크닝/지속력 이슈를 하루 루틴에서 해결
2. **상황전환형**: 출근 메이크업 → 저녁 모임 리터치 1회로 유지
3. **근접 디테일형**: 피부 결/광/밀착력 클로즈업 + 시간 경과 컷

## 4) 15초/30초 컷별 샷리스트 (초 단위)

### 4-1. 15초 샷리스트

| 구간 | 샷 목적 | 샷 설명 |
|---|---|---|
| 0.0~1.8s | Hook | 문제 제기 또는 결과 선공개 |
| 1.8~5.0s | 사용 시작 | 착용/착화 시작, 손·발 디테일 |
| 5.0~9.0s | 행동 증명 | 걷기/턴/앉기/점프 등 실제 동작 |
| 9.0~12.8s | 전환 포인트 | 전후 비교, 기능 클로즈업, 슬로모션 |
| 12.8~15.0s | CTA | 혜택/추천 CTA + 로고 |

### 4-2. 30초 샷리스트

| 구간 | 샷 목적 | 샷 설명 |
|---|---|---|
| 0.0~2.0s | Hook | 스크롤 정지 유도 |
| 2.0~8.0s | 맥락 제시 | 페인포인트 상황화 |
| 8.0~16.0s | 사용 장면 1 | 착용/착화 + 행동 증명 |
| 16.0~22.0s | 사용 장면 2 | TPO 확장/추가 동작 |
| 22.0~27.0s | 전환 포인트 | 디테일/전후/리뷰 1줄 |
| 27.0~30.0s | CTA | 기한형 오퍼 + 행동 유도 |

## 5) 툴체인 2안

### A안. 빠른 생산형 (저예산)
- 인력: 2인 (PD 1, 에디터 1)
- 촬영: 스마트폰(4K 30fps) + 짐벌 + 자연광
- 편집: CapCut 또는 Premiere 템플릿
- 자막: 자동 생성 + 수동 교정
- 생산량: 주 12~20본
- 납기: 콘셉트 3개 × 4버전 = 12본/7일

### B안. 고퀄 캠페인형 (중고예산)
- 인력: 5~7인 (디렉터/촬영/조명/스타일/편집/컬러)
- 촬영: 미러리스/시네 + 조명 + 슬라이더
- 후반: Premiere + After Effects + DaVinci
- 사운드: Foley + 믹싱
- 생산량: 주 6~10본
- 납기: 콘셉트 2개 × 3~5버전 = 6~10본/7일

## 6) A/B 테스트 설계

### Hook 3종
1. 문제 제기형: "왜 이 신발만 신고 나가면 발이 덜 아플까?"
2. 결과 선공개형: "전/후 핏 차이, 1초 만에 보임"
3. 상황 몰입형: "퇴근 후 약속? 갈아입을 시간 없음"

### CTA 2종
1. 혜택형: "오늘 자정 전 10% + 무료배송"
2. 추천형: "내 체형/사이즈 맞춤 추천 받기"

### 썸네일/첫 장면 교체 규칙
- 셀 구성: Hook 3 × CTA 2 = 6셀
- 셀당 최소: 1,000 노출
- 3초 유지율 < 35%: Hook 교체
- CTR < 1.2%: 썸네일/첫 장면 교체
- 장바구니율 < 2.0%: CTA 교체
- 승자 셀: 48시간 예산 2배 확대

## 8) 리스크 체크리스트

- [ ] 손/발 프레임 이상(손가락·발 형태) 없음

## 9) 실패 패턴 & 수정 루프 (강제)

### 빈발 실패 패턴
1. 손/발 해부학 왜곡
2. 신발 접지/착지 물리 부자연
3. 로고 늘어짐/깨짐/점프
4. 그림자 방향·광원 불일치

### 수정 루프 (최대 3회)
1. 해부학 체크 (손/발/관절)
2. 물리 체크 (접지/중심/관성)
3. 브랜드 체크 (로고/색/텍스트)
4. 법무 체크 (표현/권리)

- 라운드당 수정 SLA: 4시간
- 3회 내 미해결 컷은 폐기 후 대체컷 삽입
