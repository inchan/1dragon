# AI 영상 자동 생성 서비스 -- UX 페르소나 (7명)

> **서비스**: 상품 사진 업로드 -> TikTok/YouTube Shorts/Instagram Reels용 마케팅 영상 AI 자동 생성 (B2B+B2C, 스타트업 MVP)
>
> **작성 기준**: 2025년 한국 숏폼 마케팅 시장 데이터 기반. 글로벌 숏폼 시장 규모 약 52조 원(Statista), 한국인 하루 평균 숏폼 시청 44분(메조미디어), 숏폼 영상 1편 외주 단가 15~200만 원, AI 기반 제작 시 6~50만 원 수준(한국경제).

---

## 목차

### Part 1. B2C 페르소나 (개인 셀러/크리에이터)

개인 사업자, 글로벌 셀러, 인플루언서 등 소규모 B2C 사용자 3명의 페르소나입니다. 극한의 사용 편의성, 저렴한 가격, 스마트폰 완결 워크플로우가 핵심 가치입니다.

- **최유진 (29세)** -- 네이버 스마트스토어 1인 셀러. 월예산 12~22만 원, 시간/예산 극한 제약, 모바일 중심.
- **Sarah Chen (34세)** -- K-뷰티 글로벌 이커머스 셀러. 월예산 950~1,350만 원, 다국어/다플랫폼, API 연동 중시.
- **장하늘 (26세)** -- SNS 인플루언서/크리에이터. 월 제작비 100만 원, AI 티 안 나는 자연스러움이 핵심.

### Part 2. B2B 페르소나 (기업/에이전시/도매)

중소 브랜드, 에이전시, 대기업, 도매업체 등 B2B 사용자 4명의 페르소나입니다. 팀 워크플로우 통합, 대량 처리, 브랜드 커스터마이징, 보안/컴플라이언스가 핵심 가치입니다.

- **김민수 (32세)** -- 중소 패션 브랜드 마케팅 담당자. 월예산 200~300만 원, 시즌당 30~40 SKU, 브랜드 커스텀 중시.
- **이서연 (38세)** -- 마케팅 에이전시 디렉터. 도구비 120만 원/월, 12개 클라이언트 동시 관리, 화이트라벨/API 필수.
- **박준혁 (45세)** -- 화장품 대기업 마케팅팀 리더. 월예산 8,000만~1.2억 원, 350 SKU, 보안/승인 워크플로우 필수.
- **오성호 (42세)** -- 의류 도매업체 대표. 월예산 350만 원, SKU 3,000개, 대량 처리/극한 단순함 필수.

### 페르소나 커버리지 분석

```
                    +---------------------------------------------+
  기술               |            이서연                             |
  숙련도 高          |  Sarah        장하늘                          |
                    |                                             |
  기술               |        김민수                                 |
  숙련도 中          |                  최유진    박준혁              |
                    |                                             |
  기술               |                            오성호             |
  숙련도 低          |                                             |
                    +---------------------------------------------+
                     소규모/저예산 <-----------> 대규모/고예산
                     (개인~5명)                 (10명 이상)
```

**커버 축**:
- **B2C <-> B2B**: 최유진(순수 B2C) ~ 이서연/박준혁(B2B) ~ 오성호(B2B2C)
- **국내 <-> 글로벌**: 김민수/최유진/오성호(국내) ~ Sarah(글로벌)
- **직접 제작 <-> 위임**: 장하늘/최유진(직접) ~ 박준혁(완전 외주)
- **소량 고품질 <-> 대량 효율**: 장하늘(소량/고퀄) ~ 오성호(대량/기본퀄)
