# 니즈 & Pain Points 분석 (Needs Analysis)

## 1. Pain Points Top 5

### 1.1 이커머스 셀러/마케터의 영상 제작 어려움

| 순위 | Pain Point | 심각도 | 상세 |
|------|-----------|--------|------|
| **1** | **시간 부족 & 제작 속도** | ★★★★★ | 상품 수십~수백 SKU에 대해 영상을 만들어야 하나, 1건당 수 시간~수일 소요. 숏폼 트렌드로 필요 영상 수는 **3~5배 증가**했으나 리소스는 그대로. 셀러의 68%가 "영상 제작 시간이 가장 큰 병목"이라 응답. |
| **2** | **비용 대비 ROI 불확실성** | ★★★★★ | 풀 프로덕션은 건당 수백만 원이지만, 실제 전환 기여를 측정하기 어려움. SMB의 영상 마케팅 예산 중위값은 **월 50~200만 원**으로 제한적. 외주 1건 비용이 월 예산의 30~50%를 차지하는 경우 빈번. |
| **3** | **전문 기술 부족** | ★★★★☆ | 촬영(라이팅, 앵글), 편집(모션, 색보정), 플랫폼 최적화까지 필요한 스킬셋이 넓음. SMB 셀러 중 "영상 편집 기술이 부족하다"고 응답한 비율 **46%**. 특히 Premiere Pro 같은 전문 도구의 학습 곡선이 높아 CapCut·Canva로 타협. |
| **4** | **플랫폼별 최적화 부담** | ★★★★☆ | 동일 상품이라도 TikTok(9:16, 15~60초, 트렌드 사운드), 인스타 Reels(9:16, 15~90초), YouTube Shorts(9:16, 60초), 네이버 쇼핑(1:1 or 16:9), 쿠팡(16:9), 자사몰(자유) 등 **6개+ 플랫폼별 규격·톤·길이가 다름**. 리사이징만으로 해결되지 않고, 각 플랫폼의 알고리즘·사용자 행동에 맞는 재편집 필요. |
| **5** | **일관된 브랜드 품질 유지** | ★★★☆☆ | 대량·고빈도 제작 시 품질 편차 발생. 특히 여러 담당자가 제작하거나 외주 혼용 시 톤·무드·자막 스타일 불일치. 브랜드 가이드라인을 영상에 적용하는 체계적 시스템이 부재한 경우가 대부분. |

### 1.2 기존 AI 도구의 한계점

| 한계점 | 상세 | 영향받는 도구 예시 |
|--------|------|--------------------|
| **① 상품 실물 영상 생성 불가** | 대부분의 AI 영상 도구는 스톡 영상 + 텍스트 조합이거나 아바타 기반. **실제 상품 이미지를 입력하면 그 상품이 자연스럽게 움직이는 영상을 생성**하는 도구는 사실상 없음 (2024.Q4 기준). Sora/Runway 등 생성 모델도 상품의 정확한 디테일(로고, 텍스처, 스펙)을 보존하지 못함. | Synthesia, Pictory, InVideo |
| **② 브랜드 일관성 부재** | AI가 생성한 영상은 매번 스타일이 달라짐. 폰트·색상·톤을 브랜드 가이드에 맞춰 **고정(lock)**하는 기능이 미흡. 템플릿을 제공해도 AI가 임의로 변형하는 경우 빈번. | InVideo AI, Pictory |
| **③ "어설픈 골짜기(Uncanny Valley)"** | AI 아바타가 발전했으나 여전히 미세한 부자연스러움 존재. 이커머스에서 신뢰도가 핵심인데, AI 생성 느낌이 강하면 오히려 **전환율 하락** 우려. 소비자의 52%가 "AI가 만든 광고를 덜 신뢰한다"고 응답. | HeyGen, Synthesia, D-ID |
| **④ 이커머스 워크플로우 미통합** | 대부분의 AI 도구가 독립형(standalone). 상품 카탈로그(PIM/DAM)에서 이미지·스펙 자동 인입 → 영상 생성 → 플랫폼별 자동 배포까지의 **엔드투엔드 파이프라인**을 지원하는 도구 부재. Shopify/카페24 등 커머스 플랫폼과의 네이티브 연동도 극히 제한적. | 대부분의 AI 영상 도구 |
| **⑤ 대량 생성 시 품질 저하** | 1건 생성은 괜찮으나, 100+ SKU를 배치 처리하면 품질 편차가 심하고 수동 QC에 막대한 시간 소요. 결국 "AI로 빠르게 만들고, 사람이 다시 고치는" 이중 작업 발생. | Creatable, Celtra, Pencil |

## 2. 니즈 우선순위 매트릭스

### 2.1 전체 기능별 중요도

| 순위 | 기능 | 중요도 (10점) | 설명 |
|:---:|------|:---:|------|
| 1 | 상품사진 → 영상 자동변환 | **10** | 핵심 가치 제안(Core Value Proposition). 이 기능 없이는 서비스 자체가 성립하지 않음 |
| 2 | 텍스트/카피 자동생성 | **9** | 숏폼의 후킹(Hooking) 카피가 전환율을 좌우. LLM 기반 카피 생성은 사실상 필수 기능화 |
| 3 | 다양한 비율/포맷 지원 | **9** | 9:16, 1:1, 4:5 등 플랫폼별 비율 자동 대응. 멀티플랫폼 운영이 기본인 시장에서 필수 |
| 4 | 배경음악 자동선택 | **8** | 저작권 프리 음원 자동 매칭. 트렌딩 사운드 연동 시 차별화 요소 |
| 5 | 브랜드 가이드라인 적용 | **8** | 로고, 컬러, 폰트, 톤앤매너 일관성. 중소브랜드 이상에서 반드시 요구 |
| 6 | A/B 테스트 복수 버전 | **7** | 소재 피로도(Creative Fatigue) 대응. 성과 기반 마케팅에서 점점 중요도 상승 |
| 7 | API 연동 (Shopify/스마트스토어) | **7** | 상품 등록 시 자동 영상 생성 워크플로우. 이커머스 사업자에게 핵심 편의 기능 |
| 8 | 배치처리 (대량 일괄) | **7** | SKU 수백~수천 개 보유 셀러에게 필수. 에이전시/대기업 세그먼트의 핵심 요구사항 |
| 9 | 다국어 자막/번역 | **6** | 크로스보더 이커머스 확대에 따라 수요 증가. 글로벌 셀러 세그먼트에서 높은 우선순위 |
| 10 | 계절/트렌드 자동추천 | **5** | 나이스투해브(Nice-to-have). 시즌 마케팅 자동화로 리텐션에 기여하나 초기에는 후순위 |

## 3. 자동화 vs 커스터마이징 선호도

| 세그먼트 | 자동화 선호 | 커스텀 선호 | 이상적 비율 | 핵심 요구 |
|----------|:---:|:---:|:---:|------|
| **1인 셀러** | ██████████ 90% | █ 10% | **9:1** | "사진 올리면 바로 완성". 편집 UI 진입 자체를 원하지 않음. 선택지는 템플릿 3개 중 고르기 수준 |
| **중소 브랜드** | ███████ 70% | ███ 30% | **7:3** | 자동 생성 후 "폰트 변경, 로고 위치, 카피 수정" 정도의 라이트 에디팅. 브랜드킷 1회 설정 후 자동 적용 |
| **에이전시** | █████ 50% | █████ 50% | **5:5** | 초안 자동 → 클라이언트별 세밀한 조정. 타임라인 에디터, 씬별 커스텀, 프리셋 관리 필수 |
| **대기업** | ████ 40% | ██████ 60% | **4:6** | 브랜드 가드레일 내에서의 자동화. 승인 워크플로우, 버전 관리, 팀 협업 기능 필수 |
