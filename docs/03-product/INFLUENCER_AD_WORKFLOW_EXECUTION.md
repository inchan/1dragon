# 인플루언서형 광고 영상 목표/목적 수립 및 실행 문서

> 작성일: 2026-02-20
> 요청 맥락: "상품 사진으로 실제 인플루언서가 만드는 광고와 같은 영상 제작"

## 1) 리서치 요약 (외부 조사 결과)

### 핵심 인사이트
1. 단순 자동 생성보다 **학습 루프(성과 데이터 기반 반복 개선)**가 성과를 만든다.
2. 숏폼은 **초반 훅(0~2초) + 중반 증명 + 후반 CTA**의 구조적 설계가 중요하다.
3. 콘텐츠 품질뿐 아니라 **조회수 vs 전환(다운로드/구매)**를 분리 추적해야 한다.
4. 사람/손/표정 등 인간 맥락이 들어가야 "실제 인플루언서 광고 느낌"에 가까워진다.
5. 보안/신뢰 관점에서 외부 스킬은 검토가 필요하다.

## 2) 우리 시스템 목적(Why), 목표(What), 범위(Where)

### 목적(Why)
상품 사진 기반 자동 생성물이 "AI 느낌"에 머무르지 않고, 실제 인플루언서가 만든 것처럼 **신뢰 가능한 숏폼 광고 경험**을 제공한다.

### 목표(What / Success)
- G1. 프롬프트 구조에 **인플루언서형 내러티브(훅→증명→CTA)**를 강제한다.
- G2. 프롬프트에 **UGC 현실감 제약(핸드헬드, 인간 동작 자연성, 텍스트 안전영역)**을 반영한다.
- G3. 프롬프트 산출이 모든 I2V Provider(Runway/Hailuo/Gemini VEO/Minimax)에 일관 적용된다.

### 범위(Where / Scope)
- `apps/api/src/infrastructure/media/prompt-builder.ts`
- `apps/api/src/infrastructure/media/prompt-builder.test.ts`
- 본 실행 문서

## 3) 개선된 목표 프롬프트 (마스터 템플릿 v2)

```text
목표: 상품 사진 1장으로, 실제 인플루언서가 직접 촬영/추천한 것처럼 보이는 9:16 숏폼 광고 영상을 생성하라.

필수 구조:
- 0~2초: 스크롤을 멈추는 훅(문제 제기/결과 선공개)
- 2~10초: 사용 맥락 + 신뢰 증명(손동작/착용/사용 장면/반응)
- 10~15초: 명확한 CTA 클로즈

품질 제약:
- 제품 정체성(실루엣/로고/텍스트) 절대 보존
- 인간 표현 등장 시 해부학적 자연성 유지(손/시선/움직임)
- UGC 현실감(핸드헬드 미세 움직임, 과도한 CGI 느낌 금지)
- 텍스트 오버레이는 상단 안전영역 중심(하단 UI 가림 영역 회피)
- 광고 안전/브랜드 안전 준수
```

## 4) 실행 로그 (요청 워크플로우 매핑)

1. 리서치 ✅: X 게시글 + ClawHub Larry + OpenClaw Skills 문서 조사
2. 기획 ✅: 목적/목표/범위 정의, 프롬프트 v2 설계
3. 피드백 ✅: 기존 PromptBuilder의 한계(UGC/인간 맥락/구조 강제 부족) 확인
4. 재기획 ✅: 카테고리별 Creator Action Cue + 인플루언서 내러티브 추가
5. 개발 ✅: PromptBuilder 코드 반영
6. QA ✅: `prompt-builder` 단위 테스트 통과
7. 피드빅(2차 피드백) ✅: 테스트 관찰 결과 기반으로 문구/제약 점검
8. 코드리뷰 ✅: 변경 파일 diff 리뷰 완료
9. 퀄리키 개발(품질 강화) ✅: 카테고리별 힌트 확장 + UGC 제약 명문화
10. QA(2차) ✅: media 관련 테스트 + typecheck 통과
11. 회고 ⏳: 성능/품질 지표 기반 개선점 정리
12. 에이전트업데이트 ⏳: 운영 프롬프트/가이드 반영

## 5) 이번 개발 반영 사항

- 카테고리별 품질 힌트 확장: ELECTRONICS/FOOD/HOME/SPORTS
- 인플루언서형 내러티브 추가:
  - 실사용자(creator) 광고 톤
  - 0-2s/2-10s/10-15s 타임라인
  - UGC 현실감/인간 자연성 제약
  - 텍스트 안전영역 규칙
- 카테고리별 Creator Action Cue 추가
- 워커 단계 개선: **웨어러블 카테고리(FASHION/SPORTS/일부 ACCESSORIES-신발 키워드)**는 모델 합성(pre-composite) 선행 후 영상 생성
- API 요청의 `personaId`가 큐까지 전달되어 착장 모델 프리셋을 지정 가능
- 테스트 케이스 추가(인플루언서 타임라인/UGC 제약 검증)

## 6) 반복 실행 자동화(매 요청 워크플로우 적용)

요청사항 “방금 과정을 매번 실행”을 위해 `media-generate` 워커에 숏폼 워크플로우 자동화가 추가되었다.

- 대상 카테고리: `FASHION`
- 기본 실행 순서:
  `리서치 -> 기획 -> 피드백 -> 재기획 -> 개발 -> QA -> 피드빅 -> 코드리뷰 -> 퀄리키 개발 -> QA -> 회고 -> 에이전트업데이트`
- 자동 보강:
  - TikTok/Shorts 기반 트렌드 키워드(`ootd`, `grwm`, `fit-check`, `댓글 챌린지`) 주입
  - 훅/설명/CTA를 숏폼 챌린지형으로 정규화
  - 프롬프트에 장면 타임라인/캡션 안전영역/실사 지향 제약 추가

### API 확장 필드

`POST /api/v1/media/jobs`에 아래 옵션을 추가:

- `autoShortformWorkflow?: boolean` (기본: true로 동작)
- `creativeContext?: {`
  - `location?: string`
  - `profession?: string`
  - `identity?: string`
  - `traits?: string[]`
  - `visualStyle?: string`
  - `}`

예: 성수동/하이패션모델/한국여성/오리상 무드를 매번 반영하려면 `creativeContext`를 함께 전달한다.
