## Context

이 과제는 `knip`의 미사용 파일 보고서에 잡힌 6개 파일을 대상으로 합니다.  
해당 파일들은 바렐(export 집약) 또는 DI 헬퍼 성격으로 존재하지만, 실제 import 트리에서 진입점으로 사용되지 않는 것으로 확인되었습니다.

## Goals / Non-Goals

**Goals**
- 미사용 파일 6개를 제거하여 코드베이스 정리
- 기능 동작 변경 없이 빌드/런타임 경로를 유지
- 변경 범위를 파일 삭제로 제한

**Non-Goals**
- 새로운 API/기능 추가
- 리팩터링 또는 모듈 재배치
- 미사용 코드의 의미 있는 의미론 변경

## Decisions

### Decision 1: 직접 삭제(이동/대체 없이)

해당 파일은 재사용 지점이 확인되지 않았고, 현재 코드는 실제 구현 파일을 직접 import하는 패턴이기 때문에 이동/래핑 없이 삭제해도 경로 해석 충돌이 발생하지 않습니다.

### Decision 2: OpenSpec 과제 단위로 아카이브

이 변경을 별도 Change로 수행하여 추후 정리 의도와 삭제 내역이 추적 가능하도록 합니다.
