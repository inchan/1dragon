## 5. 성공 지표

### 5.1 North Star Metric

> **주간 활성 영상 생성 수 (Weekly Active Video Generations)**

이 지표가 North Star인 이유:
1. 영상 생성은 1Dragon의 핵심 가치 전달 행위
2. 생성 수 증가 -> 데이터 축적 -> AI 품질 개선 -> 더 많은 생성 (선순환)
3. 생성된 영상이 SNS에 게시되면 -> 바이럴(PLG) -> 신규 사용자 유입
4. 생성 빈도는 리텐션과 매출(사용량 기반 과금)에 직결

### 5.2 핵심 KPI (AARRR별)

| AARRR 단계 | KPI | 정의 | Year 1 목표 |
|-----------|-----|------|-----------|
| **Acquisition** | 가입 사용자 수 | 누적 가입 | 50,000명 |
| | 채널별 CAC | 채널별 유료 고객 획득 비용 | 평균 5,000원 |
| | 오가닉 유입 비율 | 바이럴+SEO / 전체 | 60% |
| **Activation** | Activation Rate | 가입 -> 첫 영상 생성 완료 | 40% |
| | TTV (Time-to-Value) | 가입 -> 첫 영상 확인 중위 시간 | 120초 이내 |
| | 첫 영상 SNS 공유율 | 첫 영상 -> SNS 공유 | 20% |
| **Retention** | Week 1 리텐션 | 가입 7일 후 재방문 | 30% |
| | Month 1 리텐션 | 가입 30일 후 재방문 | 15% |
| | 월간 영상 생성 수 (활성 유저) | 유료 유저 월평균 생성 수 | 15개 |
| **Revenue** | 유료 전환율 | Free -> Paid | B2C 2%+, B2B 5%+ |
| | MRR | 월간 반복 매출 | 2,700만 원 (Year 1 말) |
| | B2C ARPU | B2C 유료 유저당 월평균 매출 | 15,000~20,000원 |
| | B2B ARPU | B2B 유료 유저당 월평균 매출 | 99,000~500,000원 |
| | LTV/CAC Ratio | 고객 가치 대비 획득 비용 | 3x 이상 |
| **Referral** | K-factor (바이럴 계수) | 추천 기반 유입 | 0.5 이상 |
| | 레퍼럴 전환율 | 추천 링크 -> 가입 | 15% |

### 5.3 MVP 성공 기준 (3개월 내)

| 기준 | 지표 | 목표값 | 판정 방법 |
|------|------|--------|---------|
| **제품 가치 검증** | 첫 영상 생성 완료율 | >= 40% | 가입자 대비 첫 영상 생성 이벤트 |
| **품질 임계점 통과** | 영상 생성 성공률 | >= 95% | 생성 요청 대비 "쓸 만한" 결과물 비율 |
| **시간 가치 검증** | TTV (Time-to-Value) | <= 120초 | 가입 -> 첫 영상 확인 중위 시간 |
| **바이럴 가능성** | K-factor | >= 0.3 | 워터마크 포함 영상 -> 서비스 유입 추적 |
| **수익 가능성** | 유료 전환율 | >= 2% (B2C) | 무료 크레딧 소진 후 72시간 내 전환율 |
| **리텐션 기반** | Week 1 리텐션 | >= 25% | 가입 1주 후 재방문율 |
| **시장 적합성** | NPS | >= 40 | 베타 유저 설문 |
| **비용 효율성** | 영상 1건 원가 | <= $1.00 | API 비용 합산 (옵션 C 기준 $0.93) |
