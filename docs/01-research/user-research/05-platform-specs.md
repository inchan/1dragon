# 플랫폼별 영상 스펙 (Platform Specifications)

## 1. 주요 숏폼 플랫폼 영상 스펙 (2025년 1월 기준)

| 스펙 항목 | TikTok | YouTube Shorts | Instagram Reels | 비고 |
|----------|--------|---------------|-----------------|------|
| **권장 해상도** | 1080 × 1920 px | 1080 × 1920 px | 1080 × 1920 px | 3사 동일 |
| **비율** | **9:16** (세로) | **9:16** (세로) | **9:16** (세로) | 1:1, 4:5도 업로드 가능하나 9:16 최적 |
| **최소 해상도** | 540 × 960 px | 720 × 1280 px | 720 × 1280 px | TikTok이 가장 관대 |
| **최대 해상도** | 2160 × 3840 (4K) | 2160 × 3840 (4K) | 1920 × 1080 (피드 시) | YouTube Shorts는 4K 업로드 지원 |
| **최소 길이** | 1초 | 1초 | 3초 | Reels가 가장 긴 최소값 |
| **최대 길이** | **10분** (2024.10~) | **3분** (180초) | **3분** (180초, 2024.10~) | TikTok이 10분까지 확장했으나 숏폼 최적은 60초 이내 |
| **최적 길이 (알고리즘)** | **15~30초** | **30~60초** | **15~30초** | 각 플랫폼 알고리즘 가중치 기반 권장값 |
| **파일 포맷** | MP4, MOV | MP4, MOV, WebM | MP4, MOV | MP4 (H.264)가 범용 최적 |
| **최대 파일 크기** | 287 MB (모바일), 4GB (웹) | 256 MB | 4 GB (650MB 이하 권장) | |
| **프레임 레이트** | 24~60 fps | 24~60 fps | 24~30 fps | **30 fps**가 범용 최적 |
| **비디오 코덱** | H.264 | H.264, VP9 | H.264 | H.264 범용 |
| **오디오 코덱** | AAC | AAC | AAC | 전체 동일 |
| **오디오 비트레이트** | 128 kbps+ | 128 kbps+ | 128 kbps+ | 전체 동일 |
| **세이프 존 (Safe Zone)** | 상단 150px, 하단 270px 여백 | 상단 100px, 하단 200px 여백 | 상단 120px, 하단 250px 여백 | UI 오버레이 영역 회피 필수 |

> **스펙 출처**: TikTok Creator Portal (2024.10 업데이트), YouTube Help Center (2024.12), Instagram Help Center (2024.10). 각 플랫폼 공식 가이드 기준.

## 2. 세이프 존(Safe Zone) 시각화

```
┌──────────────────────────────┐
│    ⚠ 상단 세이프 존         │ ← 사용자명, 검색 등 UI 오버레이
│    (100~150px 여백)          │
│                              │
│                              │
│   ┌──────────────────────┐   │
│   │                      │   │
│   │   ★ 핵심 콘텐츠      │   │
│   │   (안전 영역)        │   │
│   │                      │   │
│   │   상품 이미지         │   │
│   │   핵심 카피          │   │
│   │                      │   │
│   └──────────────────────┘   │
│                              │
│    ⚠ 하단 세이프 존         │ ← 좋아요, 댓글, 공유, 캡션 등
│    (200~270px 여백)          │
│                              │
└──────────────────────────────┘
   1080 × 1920 px (9:16)
```

## 3. 멀티플랫폼 출력 매트릭스 (서비스에서 지원해야 할 조합)

| 출력 프리셋 | 비율 | 해상도 | 길이 | fps | 코덱 | 용도 |
|------------|:---:|:---:|:---:|:---:|:---:|------|
| **TikTok 숏폼** | 9:16 | 1080×1920 | 15~30초 | 30 | H.264/AAC | 틱톡 피드 최적 |
| **YouTube Shorts** | 9:16 | 1080×1920 | 30~60초 | 30 | H.264/AAC | 유튜브 쇼츠 최적 |
| **Instagram Reels** | 9:16 | 1080×1920 | 15~30초 | 30 | H.264/AAC | 릴스 피드 최적 |
| **Instagram 피드** | 4:5 | 1080×1350 | 15~30초 | 30 | H.264/AAC | 인스타 피드 정사각형형 |
| **Instagram 스토리** | 9:16 | 1080×1920 | 15초 이내 | 30 | H.264/AAC | 스토리 (자동 재생) |
| **Facebook 피드** | 1:1 | 1080×1080 | 15~30초 | 30 | H.264/AAC | 페이스북 뉴스피드 |
| **쇼핑몰 상세페이지** | 9:16 or 1:1 | 720×1280 or 720×720 | 10~20초 | 30 | H.264/AAC | 스마트스토어, 쿠팡 등 |
| **광고 소재 (Meta Ads)** | 9:16, 1:1, 4:5 | 1080 기준 | 6~15초 | 30 | H.264/AAC | 퍼포먼스 광고 |

## 4. 권장 기본 출력 설정

| 항목 | 권장값 | 이유 |
|------|:---:|------|
| **기본 비율** | 9:16 | 3대 숏폼 플랫폼 공통 |
| **기본 해상도** | 1080 × 1920 | 품질과 파일 크기의 최적 균형점 |
| **기본 길이** | 15~30초 | 알고리즘 최적 + 시청 완료율 극대화 구간 |
| **기본 fps** | 30 | 전 플랫폼 호환 + 파일 크기 효율 |
| **기본 코덱** | H.264 + AAC | 전 플랫폼 호환 |
| **기본 비트레이트** | 영상 8~12 Mbps, 오디오 128 kbps | 고화질 유지 + 업로드 제한 내 |
| **기본 출력** | 3개 동시 (TikTok/Shorts/Reels) | 원클릭 멀티플랫폼 배포 |
