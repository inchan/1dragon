# 상품 이미지 특화 AI 기술 현황 조사 보고서
**작성일**: 2025년 2월 8일 | **버전**: 1.0

---

## 개요

상품 이미지를 활용한 AI 기술 5개 분야(배경 제거, 업스케일링, Virtual Try-On, 3D 변환, 카메라 모션)의 2025년 2월 기준 현황을 조사한 보고서입니다. 각 분야별 오픈소스/상용 솔루션의 품질, 가격, 성숙도를 비교하고 시나리오별 기술 스택과 예산 플랜을 제시합니다.

---

## 목차

### Part 1. 이미지 처리 (배경 제거 + 업스케일링)

배경 제거/교체 API 5종(Remove.bg, Photoroom, ClipDrop, SAM 2, Claid.ai)과 이미지 업스케일링/리터칭 5종(Real-ESRGAN, Topaz Gigapixel, Magnific AI, SUPIR, Upscayl)을 비교합니다. Remove.bg/Photoroom이 배경 제거 프로덕션 표준이며, Topaz Gigapixel이 업스케일링 최고 품질, Real-ESRGAN이 무료 대안입니다.

[상세 보기](ai-tech-report/01-image-processing.md)

---

### Part 2. 3D 변환 + 카메라 모션 + Virtual Try-On

Virtual Try-On(IDM-VTON, Kolors, OOTDiffusion 등), 3D 회전/줌 효과(TripoSR, Zero123++, InstantMesh 등), 카메라 무브먼트 시뮬레이션(Runway Gen-3, Pika, MotionCtrl 등)을 비교합니다. Virtual Try-On은 연구->프로덕션 전환 초기 단계, 3D 변환은 TripoSR이 속도/품질 균형 최적, 카메라 모션은 Runway Gen-3이 최고 추천입니다.

[상세 보기](ai-tech-report/02-3d-motion-tryon.md)

### 시나리오별 기술 조합 추천

#### 시나리오 1: E-commerce 상품 이미지 자동화
**목표**: 배경 제거 -> 업스케일링 -> 3D 뷰 생성

**추천 스택**:
1. Remove.bg API (배경 제거) - $0.20/이미지
2. Real-ESRGAN (업스케일링 4x) - 무료
3. Tripo3D API (3D 변환) - $0.15/개

**월 예상 비용** (1000장 기준): **총 $350/월**

---

#### 시나리오 2: 패션 Virtual Try-On
**목표**: 의류 이미지 + 모델 -> 착용 영상

**추천 스택**:
1. IDM-VTON (오픈소스) - 무료 (GPU 필요)
2. Runway Gen-3 (착용 후 모션) - $10-30/분

**초기 비용**: GPU 서버 AWS p3.2xlarge (~$3/시간) 또는 로컬 RTX 4090 (~$1,500)

---

#### 시나리오 3: 프리미엄 제품 비디오 제작
**목표**: 고품질 회전/줌 영상

**추천 스택**:
1. Topaz Gigapixel (업스케일 6x) - $299 일회
2. Runway Gen-3 (카메라 모션) - $0.30/초
3. 수동 보정 (색감 조정)

**프로젝트당 비용** (10개 제품, 각 10초): **총 $329 + 일회 $299**

### 최종 권장사항

#### 즉시 프로덕션 가능 (2025년 2월)
1. **배경 제거**: Remove.bg 또는 Photoroom API
2. **업스케일링**: Topaz Gigapixel (품질 우선) 또는 Real-ESRGAN (비용 우선)
3. **3D 변환**: Tripo3D API (간단) 또는 TripoSR (자체 서빙)
4. **카메라 모션**: Runway Gen-3 API

#### 베타/실험적 (3-6개월 검증 필요)
1. **Virtual Try-On**: IDM-VTON (오픈소스, GPU 필요)
2. **고급 카메라 제어**: MotionCtrl (커스텀 개발)

#### 권장하지 않음 (2025년 2월 기준)
1. Magnific AI (상품 이미지용 - 원본 손상 위험)
2. CatVTON (아직 알파 단계)
3. Luma Dream Machine (카메라 제어 미흡)

### 예산별 추천 플랜

#### 예산 $0-500/월 (스타트업)

- 업스케일: Real-ESRGAN
- 3D 변환: TripoSR 자체 서빙
- 총 비용: ~$200/월 (GPU 포함)

- 배경 제거: Remove.bg API ($200)
- 업스케일: Topaz ($299 일회) + Real-ESRGAN
- 3D 변환: Tripo3D API ($99/월)
- 카메라 모션: Runway Gen-3 ($76/월)
- 총 비용: ~$375/월 + $299 일회

- 배경 제거: Photoroom Business ($99/월)
- 업스케일: Topaz + 전문 리터칭 ($299 일회)
- 3D 변환: Tripo3D Pro ($99/월)
- 카메라 모션: Runway Gen-3 Pro ($120/월)
- Virtual Try-On: IDM-VTON (자체 GPU 서버)
