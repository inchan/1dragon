| 글로벌 비디오 마케팅 소프트웨어 시장 | **약 $7~10B (2024)** | Grand View Research, MarketsandMarkets 등 | 2023~2024년 리포트 기반 `⚠️ 검증 필요` |
| 글로벌 숏폼 비디오 플랫폼 시장 | **약 $3~5B (2024)** | 숏폼 광고+도구+제작 합산 | 업계 추정 |

| **TAM** | **약 $5~8B (2024)** | 비디오 마케팅 SW 중 숏폼+AI 생성 영역 | |

### 1-2. SAM — 이커머스 상품 영상 자동 생성 시장

| 항목 | 추정치 | 산출 근거 |
|---|---|---|
| 이커머스 특화 비율 | TAM의 약 **25~35%** | 이커머스가 숏폼 영상 도구의 최대 수요 버티컬 |
| 자동 생성(AI 기반) 비율 | 이커머스 영상 도구의 약 **40~50%** | 템플릿 기반+AI 생성 도구가 주류화 |
| **SAM 산출** | **약 $500M ~ $1.4B (2024)** | TAM × 이커머스 비율 × AI 자동 생성 비율 |

**Bottom-Up 검증:**

| 요소 | 수치 | 비고 |
|---|---|---|
| 전세계 이커머스 셀러 (활성) | 약 **800만~1,000만** | 위 2-1, 2-2 합산 |
| 영상 도구 도입 의향/필요 셀러 비율 | 약 **30~40%** | 숏폼 콘텐츠 제작 의향 조사 기반 추정 `⚠️ 검증 필요` |
| 잠재 고객 수 | 약 **250~400만** | |
| 연간 ARPU (SaaS 기준) | 약 **$120~360** ($10~30/월) | 중소 셀러 기준 가격대 |
| **Bottom-Up SAM** | **약 $300M ~ $1.4B** | 250만 × $120 ~ 400만 × $360 |

> Top-Down과 Bottom-Up이 **$500M~$1.4B 범위에서 수렴**하므로, SAM은 약 **$500M~$1B** 수준으로 보수적 추정

`★ Insight ─────────────────────────────────────`
- SAM 추정에서 Top-Down과 Bottom-Up 두 방법론이 유사한 범위로 수렴하는 것은 추정의 신뢰도를 높여주는 긍정적 신호
- ARPU 가정($10~30/월)은 Canva Pro($12.99), CapCut Pro($7.99), Pictory($19~39) 등 기존 경쟁 제품의 가격대를 참고한 것
`─────────────────────────────────────────────────`
