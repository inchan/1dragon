## 1. 제품 개요

### 1.1 제품 비전 & 미션

**미션:**
> "모든 셀러에게 상품 사진 한 장으로 2분 안에 숏폼 마케팅 영상을 만들 수 있는 힘을 준다."

**비전 (3년):**
- **1년차:** MVP 출시 및 한국 시장 Product-Market Fit 달성 (유료 고객 2,500~6,000명, 연 매출 4.5억~21.6억 원)
- **2년차:** 글로벌 확장 (Shopify/Amazon 연동, 영미권 진출) 및 B2B 엔터프라이즈 플랜 출시
- **3년차:** 이커머스 영상 플랫폼화 (템플릿 마켓플레이스, API 생태계) 및 아시아 태평양 확장

**North Star Metric:** 주간 활성 영상 생성 수 (Weekly Active Video Generations)

### 1.2 제품 정의

1Dragon는 이커머스 셀러와 브랜드를 위한 숏폼 영상 자동 생성 SaaS 플랫폼이다. 상품 사진 1장을 업로드하면 AI가 상품을 분석하고, 하이브리드 엔진(AI 배경/효과 생성 + 원본 상품 레이어 합성)을 통해 TikTok, YouTube Shorts, Instagram Reels, 네이버 클립, 쿠팡 숏츠에 최적화된 15~60초 마케팅 영상을 2분 이내에 자동 생성한다. 기존 AI 영상 도구의 최대 약점인 상품 정체성 왜곡(로고 뭉개짐, 색상 변경 등)을 구조적으로 차단하며, "상품 사진 1장 -> 완성된 숏폼 영상" 엔드투엔드 파이프라인을 최초로 제공하는 이커머스 네이티브 솔루션이다.

### 1.4 핵심 문제 정의 (Problem Statement)

**구조적 모순:** 숏폼 영상 수요는 3~5배 폭증했으나, 이커머스 셀러의 제작 리소스(시간/비용/인력)는 정체되어 있다.

| 문제 | 현황 데이터 | 영향 |
|------|-----------|------|
| **시간 부족** | 마케터 68%가 영상 제작 시간을 최대 병목으로 지적 (HubSpot 2024) | 상품당 2.5~7시간 소요, 월 2~3개 영상이 한계 |
| **비용 부담** | 외주 1건 10~50만 원, 납기 3~5일 | SMB 영상 마케팅 예산 중위값 월 50~200만 원으로 제한적 |
| **기술 격차** | 셀러 46%가 "영상 편집 기술이 부족하다"고 응답 | Premiere Pro 학습 곡선으로 CapCut/Canva로 타협 |
| **플랫폼별 최적화** | 6개+ 플랫폼별 규격/톤/길이가 상이 | 3번 편집이 필요하나 일일이 대응 불가 |
| **시장 공백** | "상품 사진 1장 -> 완성된 숏폼 영상" 엔드투엔드 솔루션 부재 | 기존 도구는 파편화된 워크플로우 요구 |

### 2.2 에픽별 사용자 스토리 (User Story)

#### 에픽 1: 상품 이미지 업로드 & 분석

**US-1.1 상품 사진 업로드**
- **스토리:** As a 1인 셀러(최유진), I want 갤러리에서 상품 사진을 선택하여 업로드, so that 영상 제작을 바로 시작할 수 있다.
- **인수 조건:**
  - [ ] JPEG, PNG, WebP 형식의 이미지 1~5장을 업로드할 수 있다
  - [ ] 모바일 갤러리 및 카메라 직접 촬영을 지원한다
  - [ ] 업로드에서 분석 완료까지 5초 이내에 완료된다
  - [ ] 이미지 용량이 20MB 이하인 파일을 지원한다
  - [ ] 업로드 진행률이 표시된다

**US-1.2 AI 이미지 분석**
- **스토리:** As a 중소 브랜드 마케터(김민수), I want 업로드한 상품 사진을 AI가 자동 분석하여 카테고리, 속성, 키워드를 추출, so that 최적의 영상 템플릿과 카피가 자동 매칭된다.
- **인수 조건:**
  - [ ] 상품 카테고리를 자동 감지한다 (패션, 뷰티, 식품, 가전, 악세서리 등)
  - [ ] 상품 색상, 텍스처, 로고 유무를 분석한다
  - [ ] 마케팅 키워드 3~5개를 자동 추출한다
  - [ ] 분석 결과를 사용자에게 표시하고 수정할 수 있다
  - [ ] 분석 정확도 90% 이상을 달성한다

**US-1.3 이미지 자동 향상**
- **스토리:** As a 도매업체 운영자(오성호), I want 품질이 낮은 마네킹/행거 사진도 AI가 자동으로 향상, so that 조명/배경이 열악한 도매 사진으로도 괜찮은 영상을 만들 수 있다.
- **인수 조건:**
  - [ ] 저해상도 이미지를 Real-ESRGAN으로 자동 업스케일한다
  - [ ] 밝기/대비를 자동 보정한다
  - [ ] 원본 이미지와 향상된 이미지의 비교 프리뷰를 제공한다
  - [ ] 사용자가 원본 유지를 선택할 수 있다

**US-1.4 배경 자동 제거**
- **스토리:** As a 1인 셀러(최유진), I want 상품 사진의 배경이 자동으로 제거, so that AI가 새로운 배경/효과를 자연스럽게 합성할 수 있다.
- **인수 조건:**
  - [ ] Remove.bg API를 통해 1초 이내에 배경을 제거한다
  - [ ] 상품 경계면의 정확도가 95% 이상이다
  - [ ] 투명 배경 이미지를 별도로 다운로드할 수 있다
  - [ ] 배경 제거 실패 시 수동 보정 도구를 제공한다

**US-1.5 스마트스토어 상품 이미지 연동**
- **스토리:** As a 1인 셀러(최유진), I want 네이버 스마트스토어에 등록된 상품 이미지를 자동으로 가져오기, so that 별도 업로드 없이 바로 영상을 만들 수 있다.
- **인수 조건:**
  - [ ] 네이버 커머스 API를 통해 상품 목록을 조회한다
  - [ ] 상품 이미지, 상품명, 설명, 가격 정보를 자동 인입한다
  - [ ] 연동 후 상품 선택 -> 영상 생성까지의 TTV가 30초 이내이다
  - [ ] OAuth 2.0 기반의 안전한 인증을 사용한다

#### 에픽 2: AI 영상 자동 생성

**US-2.1 원클릭 영상 생성**
- **스토리:** As a 1인 셀러(최유진), I want 사진 올리고 버튼 한 번으로 영상이 완성, so that 편집 지식이 전혀 없어도 숏폼 영상을 만들 수 있다.
- **인수 조건:**
  - [ ] 사진 업로드 -> 스타일 선택 -> 생성 3단계로 완료된다
  - [ ] 영상 생성 시간이 90초 이내이다 (프로그레스 바 표시)
  - [ ] 생성된 영상의 해상도가 1080x1920(HD) 이상이다
  - [ ] 첫 영상은 최고 품질 모델(Runway Gen-4)로 생성한다 (Best-foot-forward)
  - [ ] 생성 실패 시 자동 재시도 또는 "다른 스타일로 다시 만들기"를 제공한다

**US-2.2 하이브리드 엔진 기반 상품 보존**
- **스토리:** As a 중소 브랜드 마케터(김민수), I want 영상에서 상품의 로고, 텍스처, 색상이 원본 그대로 유지, so that 브랜드 이미지가 AI에 의해 훼손되지 않는다.
- **인수 조건:**
  - [ ] 배경/효과는 AI가 생성하고, 상품은 원본 레이어로 합성한다
  - [ ] 상품 이미지의 색상 편차가 deltaE < 3 이내이다
  - [ ] 로고/텍스트가 있는 상품의 경우 왜곡률이 0%이다
  - [ ] 생성 후 자동 QC(상품 유사도 검증)를 수행한다
  - [ ] QC 실패 시 자동 재생성 또는 사용자 알림을 발송한다

**US-2.3 AI 카피라이팅**
- **스토리:** As a 1인 셀러(최유진), I want 상품에 맞는 마케팅 카피(후킹 문구, CTA)가 자동 생성, so that 카피라이팅에 시간을 쓰지 않아도 된다.
- **인수 조건:**
  - [ ] GPT-4o 기반으로 한국어 마케팅 카피를 생성한다
  - [ ] 후킹 문구(처음 1~3초), 상품 설명, CTA를 포함한다
  - [ ] 3개 이상의 카피 변형을 제안한다
  - [ ] 사용자가 카피를 직접 수정할 수 있다
  - [ ] 카피가 공정위 광고 표시법에 위반되지 않도록 자동 검증한다

**US-2.4 자동 BGM 매칭**
- **스토리:** As a 인플루언서(장하늘), I want 상품과 분위기에 맞는 BGM이 자동으로 매칭, so that 음악 선정에 시간을 쓰지 않으면서도 트렌디한 영상을 만들 수 있다.
- **인수 조건:**
  - [ ] 상품 카테고리와 영상 톤에 맞는 BGM을 자동 추천한다
  - [ ] 기본 라이브러리(20곡, Free) / 전체 라이브러리(200+곡, Starter+)를 제공한다
  - [ ] AI 생성 BGM 옵션을 제공한다 (Udio API)
  - [ ] 모든 BGM이 상업적 사용 라이선스를 보유한다
  - [ ] 사용자가 BGM을 변경하거나 자체 음원을 업로드할 수 있다

**US-2.5 TTS 내레이션 생성**
- **스토리:** As a 글로벌 셀러(Sarah Chen), I want 생성된 카피를 자연스러운 AI 음성으로 내레이션, so that 직접 녹음하지 않아도 전문적인 내레이션이 포함된 영상을 만들 수 있다.
- **인수 조건:**
  - [ ] Typecast 기반 한국어 TTS(3종 이상 음성)를 제공한다
  - [ ] ElevenLabs 기반 영어/유럽어 TTS를 제공한다 (Pro 이상)
  - [ ] 음성 톤(밝은/차분한/활기찬)을 선택할 수 있다
  - [ ] 내레이션 없이 텍스트 자막만 선택할 수 있다
  - [ ] 생성된 내레이션과 영상의 싱크가 정확하다

**US-2.6 자동 자막 생성**
- **스토리:** As a 중소 브랜드 마케터(김민수), I want 영상에 자동 자막이 삽입, so that 무음 시청 환경(약 85%)에서도 메시지가 전달된다.
- **인수 조건:**
  - [ ] Deepgram 기반으로 한국어 WER 4% 이하의 자막을 생성한다
  - [ ] 자막 타이밍이 음성과 정확히 동기화된다 (50ms 이내)
  - [ ] 자막 폰트, 크기, 색상, 위치를 사용자가 변경할 수 있다
  - [ ] 세이프 존을 고려한 기본 자막 위치가 설정된다

**US-2.7 멀티 모델 폴백**
- **스토리:** As a 시스템 관리자, I want Image-to-Video 모델이 실패하거나 품질이 미달일 때 자동으로 다른 모델로 재시도, so that 사용자에게 항상 결과물을 제공할 수 있다.
- **인수 조건:**
  - [ ] Runway Gen-4 Turbo(기본) -> Hailuo 02(폴백 1) -> Kling 2.6(폴백 2) 순서로 자동 전환한다
  - [ ] 폴백 시 사용자에게 "다른 스타일로 다시 만들기"로 표시한다
  - [ ] 모델 응답 시간이 180초 초과 시 자동 폴백한다
  - [ ] 모든 모델 실패 시 사용자에게 재시도 안내를 제공한다

#### 에픽 3: 영상 편집 & 커스터마이징

**US-3.1 스타일/템플릿 선택**
