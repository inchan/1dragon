## 8. KPI 프레임워크

### 8.1 AARRR 퍼널별 KPI

| AARRR 단계 | KPI | 정의 | 측정 도구 | 목표 (M6) | 목표 (M12) |
|-----------|-----|------|----------|----------|-----------|
| **Acquisition** | 신규 가입자 수 | 기간 내 신규 가입 | 가입 로그, UTM | 10,000명 | 50,000명 |
| | 채널별 CAC | 채널별 획득 비용 | 광고 플랫폼 + CRM | 5,000 (평균) | 3,000 (평균) |
| | 오가닉 유입 비율 | 바이럴+SEO 유입 / 전체 | GA4, UTM | 40% | 60% |
| **Activation** | Activation Rate | 가입 -> 첫 영상 생성 완료 | 이벤트 트래킹 | 35% | 45% |
| | TTV (Time-to-Value) | 가입 -> 첫 영상 완료 중위 시간 | 이벤트 타임스탬프 | 90초 | 60초 |
| | 첫 영상 SNS 공유율 | 첫 영상 -> SNS 공유 | 공유 이벤트 트래킹 | 15% | 25% |
| **Retention** | D7 리텐션 | 가입 7일 후 재방문 | 코호트 분석 | 20% | 30% |
| | D30 리텐션 | 가입 30일 후 재방문 | 코호트 분석 | 8% | 15% |
| | 월간 영상 생성 수 (활성 유저) | 유료 유저의 월평균 생성 수 | 생성 로그 | 12개 | 20개 |
| **Revenue** | MRR | 월간 반복 매출 | 결제 시스템 | 3,000만 | 1.5억 |
| | Free -> Paid 전환율 | 무료 -> 유료 전환 | 코호트 분석 | 2% | 3.5% |
| | ARPU | 유료 유저당 월평균 매출 | MRR / 유료 유저 수 | 15,000 | 25,000 |
| | LTV | 고객 생애 가치 | ARPU x 평균 구독 기간 | 90,000 | 225,000 |
| | LTV/CAC | 건전성 지표 | LTV / CAC | 3x | 5x |
| **Referral** | K-factor | 바이럴 계수 | 추천 유입 / 전체 유입 | 0.3 | 0.5 |
| | 레퍼럴 전환율 | 추천 링크 -> 가입 | UTM + 코드 | 15% | 25% |

### 8.3 대시보드 설계

| 섹션 | 지표 |
|------|------|

| 섹션 | 내용 |

## 10. 리스크 & 대응

### 10.1 GTM 리스크 Top 5

| 순위 | 리스크 | 영향도 | 발생 확률 | 위험 수준 |
|------|--------|--------|---------|---------|
| **1** | **첫 영상 품질 실패로 Activation 붕괴** | 매우 높음 | 중간 | 치명적 |
| **2** | **빅테크 무료 도구 출현** (Amazon Video Generator, TikTok Symphony 확장) | 높음 | 높음 | 높음 |
| **3** | **API 비용 급등 또는 서비스 중단** (Runway/Hailuo 의존) | 높음 | 중간 | 높음 |
| **4** | **규제 강화로 AI 생성 콘텐츠 마케팅 효과 감소** | 중간 | 높음 | 중간 |
| **5** | **네이버/쿠팡 자체 AI 도구 출시** (플랫폼 내장화) | 높음 | 중간 | 높음 |

### 10.2 각 리스크별 대응 계획

#### 리스크 1: 첫 영상 품질 실패

| 요소 | 내용 |
|------|------|
| **시나리오** | 사용자가 첫 영상 생성 시 품질이 기대에 못 미치면 40~60% 영구 이탈 |
| **선행 지표** | Activation Rate < 25%, 첫 영상 후 재방문율 < 30% |
| **대응 계획** | (1) Best-foot-forward: 첫 영상은 최고 모델로 생성 ($0.50/건 투자) (2) 업종별 최적 템플릿 자동 매칭 (3) 불만족 시 즉시 재생성 5회 무료 (4) 하이브리드 엔진으로 상품 왜곡 방지 |
| **지출 영향** | 첫 영상 비용 +70% (건당 $0.28 -> $0.50), 그러나 Activation 10% 개선은 매출에 Awareness 10% 개선 대비 3~5배 효과 |

#### 리스크 2: 빅테크 무료 도구 출현

| 요소 | 내용 |
|------|------|
| **시나리오** | Amazon이 Video Generator를 전 셀러에 무료 제공하거나, TikTok Symphony가 이커머스 특화 확장 |
| **선행 지표** | Amazon/TikTok 기능 업데이트 모니터링, 경쟁사 트래픽 급감 |

### 10.3 피벗 트리거 (언제 전략을 바꿀 것인가)

| # | 피벗 트리거 | 조건 | 피벗 방향 |

| 1 | **Activation 실패** | M3까지 Activation Rate < 20% (목표 35%) | AI 모델 품질에 집중 투자. 런칭 세그먼트를 1인 셀러에서 중소 브랜드로 변경 (품질 기준이 "Good Enough"인 세그먼트) |
